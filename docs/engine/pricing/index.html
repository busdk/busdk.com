Bus Engine Founding Technical Preview

Limited source-access preview.

The first paid Bus Engine release is a limited Technical Preview for experienced server operators. It includes Bus Engine and BusDK source access under FSL, official Bus Linux builds, updates, and best-effort support. One named operator may use the preview across unlimited test systems for personal or commercial evaluation.

Choose a plan Review capabilities

Preview license boundary

Each license includes one individual account for official releases, update services, documentation, and customer issue-tracker support. A named operator is someone who directly administers, operates, or customizes Bus Engine. Hosted application users and purchasing-only billing administrators do not consume seats. Shared accounts are not permitted; organizations may reassign licenses when roles change.

AI credits and OpenAI Codex access are not included. Customers provide their own OpenAI Codex subscription or API access for Codex-powered maintenance work. Local AI model use depends on configured Bus LLM and Ollama integrations.

Founding options

The live checkout shows the current founding preview prices. VAT is added at checkout where applicable. The binary-only Runtime subscription is intentionally deferred until Public Beta, after installation, update, recovery, and rollback paths have been exercised by source-access operators.

Monthly preview

Source access, official builds, updates, and best-effort support while the subscription is active. Intended for labs, development environments, staging systems, and non-critical workloads.

Founding one-time purchase

Includes the entire Technical Preview period plus 12 months of updates and support beginning with the Bus Engine 1.0 general-availability release.

No production SLA

Support is best effort. Interfaces, configuration formats, package selections, and upgrade behavior may change before Bus Engine 1.0.

Preview workflow

The preview focuses on one reliable workflow: install Bus Linux, configure an AI provider, ask Bus Engine for a system change, inspect the proposed change, approve it, apply it, verify it, and roll it back.

Default control loopPurpose
PlanDescribe the requested system change before touching the host.
DiffShow proposed file, package, service, or configuration changes.
ApproveRequire explicit operator approval before applying root-level changes.
ApplyApply the accepted change through the controlled Bus Engine workflow.
ValidateRun checks and collect diagnostics after the change.
RollbackReturn to the previous known state when validation fails.

What the preview includes

The preview scope is limited to Bus Engine, BusDK, and explicitly listed Engine-related modules. It includes source access under FSL terms, signed installation images and packages, exact third-party package sources, patches, build definitions, license notices, a working update channel, configuration history, audit logs, rollback, diagnostic bundles, and installation, recovery, upgrade, and known-issues documentation.

Use pre-release versions such as 0.1.0-preview.1 or 0.2.0-preview.1. Pre-release versions may be unstable and may not satisfy the compatibility expectations of the later normal release.
