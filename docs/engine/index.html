Bus Engine Founding Technical Preview

A limited early release for source-access server operators.

Bus Engine Founding Technical Preview is a limited paid early release for operators who want to evaluate Bus Engine before version 1.0. It includes the limited Bus Engine product-line source modules under the Functional Source License, official Bus Engine OS builds, updates, and best-effort technical support. It is for labs, development environments, staging systems, and non-critical workloads.

What the preview is for

The preview is for experienced operators who can inspect source, provide reproducible reports, attach diagnostic bundles, and help shape the platform before the broader beta. Commercial evaluation is allowed, but the preview does not include a production uptime or emergency-response SLA.

Source-access preview

Named Bus Engine product-line source modules are included under the Functional Source License.

Unlimited test systems

One named operator may evaluate the preview across unlimited lab and staging systems.

Update and recovery testing

Preview operators can exercise installation, updates, recovery, and rollback before the broader beta.

One reliable workflow first

The first preview concentrates on one complete system-change workflow: install Bus Engine OS, configure an AI provider, ask Bus Engine for a system change, inspect the proposed change, approve it, apply it, verify it, and roll it back. AI-controlled server changes use an explicit approval loop by default.

A successful start leaves the Engine service running, reports that state through bus engine status, and opens an SSH maintenance path for the configured target.

The change workflow is plan, diff, explicit approval, apply, validate, and rollback. The preview requires explicit approval before applying AI-authored root-level changes.

Build Bus Engine OS

Bus Engine OS is the Bus-built Linux distribution managed by AI agents. Its profiles describe the selected runtime image, kernel package, package artifacts, patches, build definitions, and validation steps. Debian cloud images can be selected as an optional compatibility input for preview runs.

The dedicated images page explains Bus Engine OS images, optional Debian compatibility inputs, kernel packages, artifact checksums, and profile examples.

AI access is separate

Bus Engine pricing does not include AI credits or OpenAI access. Customers need their own OpenAI Codex subscription or API access for Codex-powered maintenance work. Local AI model use depends on configured Bus LLM and Ollama integrations. Build, boot, checksum, and test steps remain deterministic where the task can be made deterministic.

Preview support boundary

Each preview release defines its supported architecture and target matrix in the release handoff. Interfaces, configuration formats, package selections, and upgrade behavior may change before version 1.0. Preview release versions use plain 0.x.0 numbers, such as 0.1.0.
