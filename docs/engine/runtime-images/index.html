Bus Engine Images

Runtime images are profile inputs, not the product identity.

Bus Engine OS is the Bus-built Linux distribution managed by AI agents. Runtime images are selected by Engine profiles so operators can evaluate the same Bus workflow against Bus-built images, compatibility images, kernels, packages, and signed artifacts.

Bus-built Linux first

The product direction is a Bus-controlled Linux distribution: source-managed packages, patch sets, build definitions, kernel choices, installation images, update channels, audit history, diagnostics, and rollback. AI agents help maintain that distribution through explicit planning, diffs, approval, validation, and rollback.

A runtime image is one artifact in that system. It can be replaced without changing the customer-facing workflow when a profile selects a different image, package set, kernel, or validation target.

Debian compatibility images

Debian cloud images are useful preview inputs because they are familiar, reproducible enough for compatibility testing, and already work in common virtualization paths. They are not Bus Engine OS. They are swappable runtime image artifacts used while the preview hardens installation, updates, recovery, rollback, and diagnostics.

A Bus Engine profile can select a verified Debian cloud image for one test run and a Bus Engine OS image for another. Both go through the artifact catalog, checksum verification, profile selection, and boot validation flow.

Artifact registration

The artifact catalog records the exact runtime image and kernel package selected by a profile. Engine start asks the artifact integration to fetch and verify those artifacts before boot. 

DEBIAN_IMAGE=./debian-12-genericcloud-amd64.qcow2
DEBIAN_DIGEST="sha256:<digest>"

bus artifacts catalog set debian-cloud-generic-amd64 \
  --handle "$DEBIAN_IMAGE" \
  --digest "$DEBIAN_DIGEST"

KERNEL_DEB=./linux-image-7.1.0_6_amd64.deb
KERNEL_DIGEST="sha256:<digest>"

bus artifacts catalog set bus-engine-kernel-amd64 \
  --handle "$KERNEL_DEB" \
  --digest "$KERNEL_DIGEST"

The preview can use compatibility images while Bus Engine OS matures. The product promise remains the Bus-managed Linux distribution, source tree, update channel, validation workflow, and rollback model.
