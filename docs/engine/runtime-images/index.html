Bus Engine Images

Bus Engine OS comes first.

Bus Engine OS is the Bus-built Linux distribution for Bus Engine. In the preview, Engine profiles select the Bus-built image, kernel, packages, and signed artifacts for each target. Debian cloud images can also be selected for compatibility checks.

Bus Engine OS first

Bus Engine OS is a Bus-controlled Linux distribution: source-managed packages, patch sets, build definitions, kernel choices, installation images, update channels, diagnostics, and rollback paths. The preview exposes those pieces through controlled planning, diffs, approval, validation, and rollback.

A runtime image is one artifact in that system. It can be replaced without changing the customer-facing workflow when a profile selects a different image, package set, kernel, or validation target.

Optional Debian compatibility images

Debian cloud images are useful preview inputs because they are familiar and already work in common virtualization paths. They help compare compatibility behavior while Bus Engine OS installation, updates, recovery, rollback, and diagnostics mature.

A Bus Engine profile can select a verified Debian cloud image for one test run and a Bus Engine OS image for another. Both go through the artifact catalog, checksum verification, profile selection, and boot validation flow.

Artifact registration

The artifact catalog records the exact runtime image and kernel package selected by a profile. Engine start asks the artifact integration to fetch and verify those artifacts before boot. 

DEBIAN_IMAGE=./debian-12-genericcloud-amd64.qcow2
DEBIAN_DIGEST="sha256:<digest>"

bus artifacts catalog set debian-cloud-generic-amd64 \
  --handle "$DEBIAN_IMAGE" \
  --digest "$DEBIAN_DIGEST"

KERNEL_DEB=./linux-image-7.1.0_6_amd64.deb
KERNEL_DIGEST="sha256:<digest>"

bus artifacts catalog set bus-engine-kernel-amd64 \
  --handle "$KERNEL_DEB" \
  --digest "$KERNEL_DIGEST"

Successful registration records the artifact handle and digest in the catalog, so Engine profiles can select the exact image and kernel package for a boot target.
