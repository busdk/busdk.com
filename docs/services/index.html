Bus Services

Predictable service stacks without requiring virtualization.

Bus Services turns project dependencies into public-safe services.yml stacks you can validate, plan, start, inspect, and stop as ordinary user-land services.

Read docs Browse BusDK products

What it is for

Bus Services is for developers and operators who need repeatable project-level service stacks without relying on drifting README steps, ad hoc shell scripts, or a container-only assumption.

Core workflows

  • Define public service configuration in services.yml.
  • Validate and inspect a non-secret plan before startup.
  • Start services, inspect status, and stop the resolved running stack.
  • Use OS, container, VM, network, or systemd controls when isolation is required.

Modules behind the product

The product owns bus-services, bus-api-provider-services, and bus-integration-services. Runtime/provider modules participate when a service type uses them, but they stay owned by their product or platform boundary.
