Bus Services

Modules behind predictable service stacks.

Bus Services is a product for local and project service orchestration. Runtime modules can participate, but they are not marketed as separate service-stack products.

Core product modules

  • bus-services for service contract parsing, validation, planning, start, status, and stop.
  • bus-api-provider-services for API-hosted service lifecycle access.
  • bus-integration-services for worker-side service lifecycle integration.
  • OS, container, VM, network, and systemd modules when a resolved service type needs them.
