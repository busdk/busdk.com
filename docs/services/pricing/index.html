Bus Services Pricing

Free binary testing for two weeks.

Bus Services is available as a binary tool for testing service stacks today. Each installation is valid for two weeks. After that, continued use requires a subscription or staying current with the latest released binary, for example by reinstalling every two weeks.

Current access

Binary testing

Test Bus Services with release binaries at no charge for two weeks from installation. This is the right path for evaluating services.yml, local stacks, Docker images, and non-secret status output.

What is included

The binary test path covers the user-facing dispatcher, the Services CLI, local integration runtime, stack validation, planning, startup, status, and shutdown workflows exposed by the release.

What is not live yet

Source-code releases, paid source subscriptions, and hosted support products are not available for self-service checkout yet. Until subscriptions are live, teams that need longer binary evaluation should stay on the latest release.

Evaluate before buying

Start with the two-week binary path and prove the operational workflow first: define a stack, run bus services up, inspect with bus services list, and stop with bus services down. If the stack becomes part of a team workflow, plan for a subscription with source-code access and Issue tracker support, or keep evaluating by reinstalling the latest release before the test window expires.
