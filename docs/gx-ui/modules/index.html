Bus GX/UI Library

Modules behind the Go-native UI product.

Bus GX/UI is a product line for teams that want React-like authoring and reusable UI surfaces while keeping Go as the primary product implementation language.

Core product modules

  • bus-gx for GX source, compilation, render trees, runtime bridges, and tests.
  • bus-ui for reusable shells, forms, tables, terminals, assistant UI, and evidence components.
  • Portal and product module adapters that mount UI without owning product policy.
  • Deterministic test harnesses for generated render roots and component behavior.
