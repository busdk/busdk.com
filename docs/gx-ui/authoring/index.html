Bus GX/UI Tutorial

Write frontend components as Go-owned source.

A .gx file is a Go package file with markup inside Go functions. The compiler lowers that markup into deterministic Go rendering while keeping props, callbacks, children, and validation visible to normal Go review.

Start with a component

Component props are ordinary Go structs. Strings become escaped text, nodes stay nodes, slices of nodes splice into the child list, and optional fields remain visible in the type definition. 

package notesui

import "github.com/busdk/bus-gx/pkg/gx"

type NoticeProps struct {
  Title    string
  Tone     string `gx:",optional"`
  Children []gx.Node
}

func Notice(props NoticeProps) gx.Node {
  return <section class={"notice " + props.Tone}>
    <h2>{props.Title}</h2>
    {props.Children}
  </section>
}

Add callbacks and safe intrinsic elements

Lowercase tags map to validated intrinsic elements. Callback props stay as Go functions in the render tree and are omitted from serialized HTML until a runtime host wires them. 

type EditorProps struct {
  Title    string
  OnTitle  func(string)
  OnSubmit func(gx.SubmitEvent) gx.Result
}

func NoteEditor(props EditorProps) gx.Node {
  return <form onSubmit={props.OnSubmit}>
    <label for="title">Title</label>
    <input id="title" name="title" value={props.Title} onInput={props.OnTitle}></input>
    <button type="submit">Save</button>
  </form>
}

Built-in callback payloads

GX supports typed click, submit, input/change, keyboard, focus/blur, file-input, and drag/drop event payloads. Invalid callback signatures produce diagnostics before generated Go is accepted.

Format, lint, and compile

The source tools are deterministic. Format and lint can run before compile, while compile writes generated Go in the same package as the human-authored source. 

bus gx fmt --check notes.gx
bus gx lint --format json notes.gx
bus gx compile notes.gx --output notes_gx_generated.go

Generated code keeps the Go declaration shape and replaces markup expressions with calls such as gx.Element, gx.Text, and component functions.

Render without a host

Components can render to stable HTML for server output, snapshots, and unit tests. This is useful even when the same component is later mounted into a browser host. 

html, err := gx.RenderHTML(Notice(NoticeProps{
  Title: "Ready",
  Tone:  "success",
  Children: []gx.Node{
    gx.Element("p", nil, gx.Text("Generated by Go.")),
  },
}))
if err != nil {
  return err
}
