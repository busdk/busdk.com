GX Framework Tutorial

Write frontend components as Go-owned source.

A .gx file is a Go package file with markup inside Go functions. The authoring flow is split into pages for source files, component functions, props and children, generated Go, and the runtime surfaces that consume the result.

See the source-file shape, formatter, linter, and compile command.

Generated Go

What the authoring flow gives you

Component props stay visible in Go types, child content stays explicit in the tree, and the compiled output stays in the same package for review and testing.
