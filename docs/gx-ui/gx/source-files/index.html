GX Framework

Source files

A .gx file is a Go package file with markup expressions in Go declarations and functions.

Source shape

GX keeps package names, imports, types, functions, and top-level declarations in Go form. Markup lowers to generated Go in the same package.

package notesui

import "github.com/busdk/bus-gx/pkg/gx"

func NoteTitle(title string) gx.Node {
  return <h2 class="note-title">{title}</h2>
}

Commands

bus gx fmt --check file.gxChecks canonical source formatting.
bus gx lint --format json file.gxReports source diagnostics without writing generated files.
bus gx compile file.gx --output file.goWrites generated Go rendering code.
