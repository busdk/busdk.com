GX Framework

Testing

GX test helpers keep rendering and generated output easy to assert from Go tests.

Helpers

gxtest.RenderHTMLRender and fail the test on render errors.
gxtest.VNodeInspect the normalized render tree.
gxtest.RequireProp[T]Read a typed VNode prop.
gxtest.CompileGXCompile source in tests.
gxtest.MountWASMRun browser-backed mount assertions.

Example

html := gxtest.RenderHTML(t, Notice(NoticeProps{
  Title: "Ready",
}))
