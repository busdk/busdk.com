GX Framework

Runtime bridges

GX can render without a runtime. Runtime bridges are used only when a host needs mounted interaction.

Mount APIs

gxwasm.MountMounts a root function into a host selector.
gxwasm.MountAppMounts a stateful app root.
Handle.RequestUpdateRequests a rerender for one mounted root.
Handle.UnmountDisposes one mounted root.

Boundary

GX runtime bridges do not own provider calls, secrets, storage, authorization, or product policy. Hosts provide those pieces explicitly.
