GX Nodes

Element builds deterministic fragments.

Use element primitives when the reusable boundary is a small HTML fragment assembled from a tag, safe props, and child nodes.

Public API

Functionsui.El, ui.VEl
Use forSmall deterministic HTML fragments and virtual DOM element nodes.

node := ui.El("section", ui.P("class", "notice"),

.gx source

package nodes

import gx "github.com/busdk/bus-gx/pkg/gx"

func Notice() gx.Node {
  return <section class="notice">
    <h2><Text value={"Ready"}></Text></h2>
    <p><Text value={"The fragment is deterministic."}></Text></p>
  </section>
}
