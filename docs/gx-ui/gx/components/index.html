GX Framework

Component functions

A GX component is a Go function that returns gx.Node.

Props and children

Props are ordinary Go structs. Child nodes are passed through a Children []gx.Node field.

type PanelProps struct {
  Title    string
  Children []gx.Node
}

func Panel(props PanelProps) gx.Node {
  return <section class="panel">
    <h2>{props.Title}</h2>
    {props.Children}
  </section>
}

Rules

  • Uppercase tags call component functions.
  • Lowercase tags render intrinsic elements.
  • Strings become escaped text.
  • gx.Node values become children.
  • []gx.Node values splice in source order.
