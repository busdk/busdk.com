GX Framework

Rendering

GX rendering is deterministic so pages, snapshots, and tests can compare stable output.

Core rendering APIs

gx.NodeInterface returned by component functions.
gx.ElementCreates an intrinsic element node.
gx.TextCreates escaped text.
gx.FragmentGroups children without an extra element.
gx.RenderHTMLRenders stable HTML.

Example

html, err := gx.RenderHTML(gx.Element("p",
  gx.Props{"class": "message"},
  gx.Text("Hello <Bus>"),
))
