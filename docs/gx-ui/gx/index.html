GX Framework

The frontend foundation.

GX is the source format, compiler, render tree, runtime bridge, and test layer. Bus UI is built on top of it.

Source files

Write markup inside Go package files and compile it into Go.

Component functions

Use typed props, children, and ordinary Go composition.

Events

Pass typed callback functions through the render tree.

Rendering

Render stable HTML and normalized VNodes.

Runtime bridges

Mount Go component trees where a host needs runtime interaction.

Testing

Assert generated output, HTML, VNodes, and mounted behavior.

What belongs to GX

GX owns the low-level component language: source parsing, formatting, linting, compilation, render-tree constructors, deterministic HTML rendering, callback payloads, runtime mounts, and core test helpers.

hello.gx
func Hello(name string) gx.Node {
  return <p class="message">
    Hello {name}
  </p>
}
