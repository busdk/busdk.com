GX/UI Pricing

Choose the UI layer you need.

Bus GX and Bus UI are commercial source-available Bus modules. Buy one year of FSL-licensed source access, with GitHub repository invitations handled manually after checkout and GitHub Issues available for support.

One-year repository access

Each purchase grants one year of GitHub repository access as an outside collaborator. After payment, we email setup details and send the repository invitation to the purchaser's GitHub account.

License and support

Source access is licensed under FSL, converting to MIT or Apache 2.0 two years after release. Repository instructions are included, and support questions can be placed as GitHub Issues.

Checkout and VAT

Customers are charged immediately during Stripe checkout. VAT is added at checkout where applicable. If checkout is unavailable, contact sales@hg.fi.

GX is the library layer

Bus GX gives your team the component language and runtime primitives. It is the right fit when you want to define your own design system, component inventory, and product-specific presentation rules.

notice.gx
func FoundationNotice(props NoticeProps) gx.Node {
  return <section class="notice">
    <h2>{props.Title}</h2>
    {props.Children}
  </section>
}

var gxPackage = <FoundationNotice title={"Bus GX"}>
  Build your own product components on the GX library.
</FoundationNotice>

Bus UI includes GX

Bus UI includes the GX foundation and adds the complete supported component package. It is the practical choice when the goal is to ship product screens with shared, tested UI contracts instead of starting from primitives.

Learn GX, browse Bus UI, or review GX/UI pricing.
