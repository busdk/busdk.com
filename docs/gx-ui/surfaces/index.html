Bus UI Product Surfaces

Build real product surfaces without moving policy out of Go.

Bus UI is used by portal modules that need structured pages, provider-backed data, uploads, evidence, assistant workflows, terminal sessions, and deterministic tests.

Portal module shell

A module can render a shared shell and fill page slots with module-owned content. The generic portal host owns mounting, token-aware URLs, public config, assets, and security headers; the product module owns the business behavior.

The pkg/ui facade covers the public shell and surface helpers. Evidence, assistant, and terminal pages show the package-specific node APIs and explicit render boundaries for serialized HTML. 

import (
  gx "github.com/busdk/bus-gx/pkg/gx"
)

navNodes := []gx.Node{
  gx.Element("a", gx.Props{"href": "/modules/accounting/"}, gx.Text("Overview")),
  gx.Element("a", gx.Props{"href": "/modules/accounting/files"}, gx.Text("Files")),
}

mainNodes := []gx.Node{
  gx.Element("main", nil, gx.Text("Files")),
}

The shell render boundary consumes those node slices when a page needs serialized HTML.

Uploads and evidence

File inputs and drop zones normalize public metadata. Evidence URL helpers validate safe open/download links, while previews embed only approved content types and show public fallback text when a file cannot be previewed inline. 

node := ui.EvidencePreview(ui.EvidencePreviewProps{
  Title:       "Receipt PDF",
  ContentType: "application/pdf",
  PreviewURL:  "/modules/accounting/api/evidence/receipt.pdf",
  OpenURL:     "/modules/accounting/api/evidence/receipt.pdf",
  DownloadURL: "/modules/accounting/api/evidence/receipt.pdf?download=1",
  Fallback:    "Open or download this evidence file.",
})

html, err := gx.RenderHTML(node)

Provider errors and projections

Provider errors can be redacted into public-safe summaries with request ids, field-level errors, retry controls, and severity mapping. Projection details render record fields and evidence actions while the product module owns authorization and data meaning. 

node := ui.ProviderError(ui.ProviderErrorProps{
  Title:     "Provider request failed",
  Summary:   "The accounting provider could not prepare the evidence pack.",
  RequestID: "req_20260613_001",
  Status:    503,
})

html, err := gx.RenderHTML(node)

Assistant workbench

Assistant surfaces cover thread lists, messages, model selection, attachments, approvals, review status, isolation conflicts, and close guards. Transport, execution, persistence, billing, and authorization stay in the host module. 

import (
  gx "github.com/busdk/bus-gx/pkg/gx"
  assistantui "github.com/busdk/bus-ui/pkg/assistantui"
)

node := assistantui.AIModelSelect(assistantui.AIModelSelectProps{
  Current: "gpt-5.4-mini",
  Options: []assistantui.AIModelOption{
    {ID: "gpt-5.4-mini", Label: "GPT 5.4 mini"},
    {ID: "gpt-5.4", Label: "GPT 5.4", Disabled: true, Reason: "Requires approval"},
  },
  OnChange: func(event assistantui.AIModelEvent) assistantui.Result {
    return assistantui.Success(event.ModelID)
  },
})

html, err := gx.RenderHTML(node)

Terminal session UI

Terminal helpers normalize stream aliases, validate caller-order sequences, escape output chunks, render idle, running, waiting, exited, and error states, and expose typed submit, input, exit, and approval events. 

import (
  gx "github.com/busdk/bus-gx/pkg/gx"
  terminalui "github.com/busdk/bus-ui/pkg/terminalui"
)

seq1, seq2 := 1, 2
node := terminalui.TerminalSessionPanel(terminalui.TerminalSessionPanelProps{
  Title:     "Verification",
  Command:   "go test ./...",
  SessionID: "sess_123",
  State:     terminalui.TerminalSessionStateRunning,
  Output: []terminalui.TerminalChunk{
    {Stream: "stdout", Sequence: &seq1, Text: "go test ./..."},
    {Stream: "stdout", Sequence: &seq2, Text: "ok"},
  },
})

html, err := gx.RenderHTML(node)

Catalog and artifact metadata

Component catalog metadata and UI artifact validation make it possible to audit which files are human-authored GX, generated Go, runtime config, resource contracts, runtime fixtures, and render fixtures. 

err := uiartifact.ValidateArtifacts([]uiartifact.Artifact{
  {
    Kind:      uiartifact.GXSource,
    Owner:     "bus-portal-accounting",
    Source:    "pkg/accountingportal/accounting_files.gx",
    Generated: "pkg/accountingportal/accounting_files_gx_generated.go",
  },
  {
    Kind:   uiartifact.GeneratedGo,
    Owner:  "bus-portal-accounting",
    Source: "pkg/accountingportal/accounting_files_gx_generated.go",
  },
})
