Bus GX/UI Library

Go-native UI components with TSX-like authoring.

Bus GX/UI Library helps Go-heavy product teams build reusable, testable frontend surfaces without moving product ownership into a separate JavaScript-first application.

Read docs Discuss a UI migration

What it is for

This product is for Go developers, platform engineers, BusDK module authors, and AI-native engineering teams that need frontend components to be typed, inspectable, deterministic, and easy to review.

Core workflows

  • Write TSX-like .gx UI roots near Go code.
  • Compile GX source into generated Go render roots.
  • Use shared Bus UI components for shells, status, forms, tables, assistant UI, evidence, terminal, and portal surfaces.
  • Keep validation, authorization, provider behavior, secrets, and business policy in the owning product module.

Modules behind the product

bus-gx owns the source format, compiler, render tree, browser runtime, and test utilities. bus-ui owns reusable components, adapters, CSS hooks, mount helpers, portal integration surfaces, and test harnesses.
