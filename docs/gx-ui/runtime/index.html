GX Runtime Tutorial

Render, mount, dispatch, and test from Go.

Runtime helpers let a host render deterministic HTML, mount stateful component trees, dispatch action/resource results, and bridge into Go/WASM only when the host needs browser-specific interaction. The pkg/ui facade stays the preferred public path for the core checked component set while advanced runtime surfaces continue to move over incrementally.

Mount a stateful component tree

MountedApp keeps hook state across renders and records diagnostics when disposed state tries to update after unmount. The same contract can run without browser globals for server-side tests. 

import (
  gx "github.com/busdk/bus-gx/pkg/gx"
  uikit "github.com/busdk/bus-ui/pkg/uikit"
  uiportal "github.com/busdk/bus-ui/pkg/uiportal"
)

app := uikit.NewMountedGXNodeApp("counter", func(ctx *uikit.RenderCtx) gx.Node {
  count, setCount := uikit.UseState(ctx, 0)
  return gx.Element("button", gx.Props{
    "data-ui-action": "increment",
    "onClick": func() { setCount(count + 1) },
  }, gx.Text(fmt.Sprintf("Count %d", count)))
})

html, err := app.Render()

Route actions and provider requests

Actions return public result shapes. Resources validate method, base, and path before a host client sends a request. Provider details, credentials, and retry policy stay outside the component. 

state := uikit.NewActionState()
actions := uikit.ActionSet[string]{
  "files.refresh": {
    Token: "files.refresh",
    RunResult: func(moduleID string) uikit.Result {
      return uikit.Success(map[string]string{"module": moduleID})
    },
  },
}

result := uikit.RunAction(actions, state, "files.refresh", "accounting")

request, err := uikit.NormalizeResourceRequest(uikit.ResourceRequest{
  Name:   "FilesIndex",
  Method: uikit.ResourceMethodGet,
  Base:   "module",
  Path:   "/api/files",
})

Pass public runtime config

Portal hosts can expose non-secret runtime config, same-origin module URLs, declared provider origins, assets, and logging callbacks through checked host context helpers. Secret-bearing values are rejected instead of rendered. 

import uiportal "github.com/busdk/bus-ui/pkg/uiportal"

page := gx.Element("main", nil, gx.Text("Accounting"))

shell, err := uiportal.PortalShellChecked(uiportal.PortalShellProps{
  Title: "Accounting",
  HostContext: uiportal.HostContext{
    ModuleID:           "accounting",
    BasePath:           "/modules/accounting/",
    PortalBasePath:     "/",
    SameOriginBasePath: "/",
    PublicRuntimeConfig: map[string]any{
      "locale": "fi-FI",
    },
  },
  MainNodes: []gx.Node{page},
  RenderRuntimeConfig: true,
})

Test rendering and interaction

Test helpers cover generated GX output, deterministic HTML, mounted app behavior, fake resources, fake file/drop readers, fake terminal sources, and browser-backed Go/WASM paths. 

func TestStatusPanel(t *testing.T) {
  html := gxtest.RenderHTML(t, StatusPage(StatusPageProps{
    Message: "Ready",
  }))
  uikittest.AssertHTMLContains(t, html, `data-ui-component="StatusPill"`)
}

func TestResourceRequest(t *testing.T) {
  stub := uikittest.ResourceStub{
    Result: uikit.Success("ok"),
  }
  result := uikit.RunResource(&stub, request, nil)
  if result.Kind != uikit.ResultKindSuccess {
    t.Fatalf("unexpected result: %s", result.Kind)
  }
}
