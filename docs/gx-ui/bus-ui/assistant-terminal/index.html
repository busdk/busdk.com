Bus UI Assistant And Terminal

Workbench surfaces for guided operations.

Assistant and terminal components keep model choice, approvals, review state, thread isolation, session output, and operator input consistent across Bus products.

Workbench pieces

PieceUse it forNames
Assistant shellThread layout, message panels, composer area, and workbench chrome.AssistantShellChecked, AIPanelChecked, AIComposerChecked
ControlsModel choice, approval prompts, review status, and thread isolation cues.AIModelSelectChecked, AIApprovalsChecked, AIReviewStatusChecked, AIThreadIsolationChecked
TerminalSession panels, command input, output chunks, prompts, and approvals.TerminalSessionPanelChecked, TerminalOutputChecked, TerminalInputChecked
AdaptersConnect terminal sources and assistant state to checked rendering.terminal source and adapter helpers

Example

panel, err := uikit.AIPanelChecked(uikit.AIPanelProps{
  Title: "Review",
  BodyHTML: uikit.AIReviewStatus(uikit.AIReviewStatusProps{
    State:   uikit.AIReviewAccepted,
    Message: "Changes accepted by supervisor.",
  }),
})
