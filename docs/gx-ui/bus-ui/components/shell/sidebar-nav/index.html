Bus UI Shells

SidebarNav renders the left-rail choices.

Use SidebarNavChecked when a sidebar needs safe links, callback-backed controls, active state, collapse metadata, and deterministic item ids.

Checked API

Functionui.SidebarNavChecked
Propsui.SidebarNavProps
Item propsui.SidebarNavItemProps
Use forReusable navigation rails with link and typed control targets.

Example

import ui "github.com/busdk/bus-ui/pkg/ui"

nav, err := ui.SidebarNavChecked(ui.SidebarNavProps{
  AppLabel:  "Accounting",
  MountPath: "/accounting/",
  Items: []ui.SidebarNavItemProps{
    {ID: "overview", Label: "Overview", Href: "index.html", Active: true},
    {ID: "files", Label: "Files", Href: "files/index.html"},
  },
})
