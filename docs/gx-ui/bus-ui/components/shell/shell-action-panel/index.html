Bus UI Shells

ShellActionPanel keeps shell actions bounded.

Use ShellActionPanelChecked for a shell-level panel with a required title, typed body nodes, validated controls, and optional footer content.

Checked API

Functionui.ShellActionPanelChecked
Propsui.ShellActionPanelCheckedProps
Control propsui.ShellActionPanelControl
Use forValidated shell panels that include actions beside descriptive content.

Example

import (
  gx "github.com/busdk/bus-gx/pkg/gx"
  ui "github.com/busdk/bus-ui/pkg/ui"
)

panel, err := ui.ShellActionPanelChecked(ui.ShellActionPanelCheckedProps{
  Title: "Review import",
  Body: []gx.Node{
    gx.Element("p", nil, gx.Text("Validate the imported evidence before posting.")),
  },
  Actions: []ui.ShellActionPanelControl{{
    Label: "Approve",
    Control: ui.ControlProps{Action: "approve-import"},
  }},
})
