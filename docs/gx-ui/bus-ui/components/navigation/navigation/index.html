Bus UI Navigation

Navigation renders generic section lists.

Use Navigation for labeled navigation lists where route policy stays in the owning module and Bus UI validates item ids, labels, and targets.

Public API

Functionui.Navigation
Propsui.NavigationProps
Item propsui.NavigationItem
Use forGeneric navigation rails and section lists with active state.

Go API

import (
  gx "github.com/busdk/bus-gx/pkg/gx"
  ui "github.com/busdk/bus-ui/pkg/ui"
)

node, err := ui.Navigation(ui.NavigationProps{
  Label:  "Settings",
  Active: "billing",
  Items: []ui.NavigationItem{
    {ID: "profile", Label: "Profile", Href: "profile/index.html"},
    {ID: "billing", Label: "Billing", Href: "billing/index.html"},
  },
})

html, err := gx.RenderHTML(node)

In .gx source, wrap the navigation item list in a component function and use lower-camel tag attributes for the exported props.

In .gx source, product navigation is a semantic link tree rather than a Go-side node slice.

.gx source

package navigationui

import gx "github.com/busdk/bus-gx/pkg/gx"

type ProductNavigationProps struct {
  Current string
}

func ProductNavigation(props ProductNavigationProps) gx.Node {
  return <nav class="product-navigation" aria-label="Workspace">
  <a href="/work/index.html"><Text value={"Work"}></Text></a>
  <a aria-current="page" href="/work/imports.html"><Text value={props.Current}></Text></a>
</nav>
}

var workspaceNavigation = <ProductNavigation current={"Imports"}></ProductNavigation>
