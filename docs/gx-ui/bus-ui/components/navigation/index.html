Bus UI Navigation Components

Move between module views without moving policy into the view.

Navigation helpers are still part of pkg/uikit. Use them when a module needs tabs, menus, or a generic navigation rail, and keep route and target policy in the owning module.

Checked APIs

ComponentUse it forChecked APICurrent path
MenuImmediate command menus with a trigger and bounded choices.MenuChecked / MenuPropspkg/uikit
TabsSibling views that swap by stable active tab id.TabsChecked / TabsPropspkg/uikit
NavigationGeneric navigation rails and section lists.NavigationChecked / NavigationPropspkg/uikit

Example

Tabs are the simplest fit when the screen stays in one module and only the visible section changes. 

import uikit "github.com/busdk/bus-ui/pkg/uikit"

tabs, err := uikit.TabsChecked(uikit.TabsProps{
  Label:  "Accounting navigation",
  Active: "files",
  Items: []uikit.TabItem{
    {ID: "overview", Label: "Overview", Href: "/modules/accounting/index.html"},
    {ID: "files", Label: "Files", Href: "/modules/accounting/files/index.html"},
  },
})
