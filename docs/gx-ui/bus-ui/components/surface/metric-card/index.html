Bus UI Surfaces

MetricCard presents one dashboard number.

Use MetricCard for headline numbers with optional detail text and semantic status accents.

Public API

Functionui.MetricCard
Propsui.MetricCardProps
Use forDashboard metrics, counters, and summarized state.

Example

Go API

import (
  gx "github.com/busdk/bus-gx/pkg/gx"
  ui "github.com/busdk/bus-ui/pkg/ui"
)

node := ui.MetricCard(ui.MetricCardProps{
  Title:  "Ready files",
  Value:  "12",
  Detail: "3 waiting for review",
  Status: ui.StatusSuccess,
})

html, err := gx.RenderHTML(node)

In .gx source, a direct wrapper can set the fixed status value while exposing the readable fields as attributes.

.gx source

package surfaceui

import (
  gx "github.com/busdk/bus-gx/pkg/gx"
  ui "github.com/busdk/bus-ui/pkg/ui"
)

type ReadyFilesMetricProps struct {
  Title  string
  Value  string
  Detail string
}

func ReadyFilesMetric(props ReadyFilesMetricProps) gx.Node {
  return ui.MetricCard(ui.MetricCardProps{
    Title:  props.Title,
    Value:  props.Value,
    Detail: props.Detail,
    Status: ui.StatusSuccess,
  })
}

type MetricsSummaryProps struct{}

func MetricsSummary(props MetricsSummaryProps) gx.Node {
  return <ReadyFilesMetric title="Ready files" value="12" detail="3 waiting for review"></ReadyFilesMetric>
}
