Bus UI Status

ResultPanel summarizes an operation.

Use ResultPanelChecked after a submission, import, or provider action needs a visible outcome with optional follow-up actions.

Public API

Functionui.ResultPanelChecked
Propsui.ResultPanelProps
Use forOperation outcomes with title, summary, status, and actions.

Example

import ui "github.com/busdk/bus-ui/pkg/ui"

result, err := ui.ResultPanelChecked(ui.ResultPanelProps{
  Status:  ui.StatusSuccess,
  Title:   "Import complete",
  Summary: "12 rows were accepted.",
})
