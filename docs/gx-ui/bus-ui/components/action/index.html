Bus UI Action Components

Buttons and action bars with consistent control semantics.

Use action components for the visible controls that move a screen forward. The public facade already exposes ui.Button and ui.ButtonProps, while the more specialized link, icon, and event-bar helpers still live on pkg/uikit as compatibility and implementation surfaces.

Public APIs

ComponentUse it forPublic APICurrent path
ButtonPrimary, secondary, danger, and ghost actions.ButtonPropspkg/ui wrapper, checked helper on pkg/uikit
LinkButtonAnchor-like actions styled as buttons.LinkButtonPropspkg/uikit compatibility boundary
IconButtonCompact icon-only or icon-leading actions.IconButtonPropspkg/uikit compatibility boundary
EventBarDense rows of action controls inside headers or panels.EventBarPropspkg/uikit compatibility boundary

Example

The public facade can already render the common button shape. When a module only needs a labelled action, the wrapper is the simplest entry point. 

import ui "github.com/busdk/bus-ui/pkg/ui"

html := ui.Button(ui.ButtonProps{
  Label:   "Save draft",
  Variant: ui.ButtonPrimary,
})
