Bus UI Components

Shared structure for product surfaces.

These family pages explain the checked component APIs one layer at a time. Some surfaces already use the public pkg/ui facade; shells and navigation still live on pkg/uikit, so the pages call out the current path explicitly.

Family pages

FamilyUse it forPage
ShellsApplication frames, module pages, sidebar layouts, and shell action panels.Shell
NavigationMenus, tabs, and generic navigation rails.Navigation
ActionsButtons, button links, icon buttons, and action bars.Action
SurfacesPanels, surface cards, and metric cards.Surface

Example

The shell family is still anchored in pkg/uikit. Use the page-shell helper when the module already owns its own header, body, and footer structure. 

import (
  gx "github.com/busdk/bus-gx/pkg/gx"
  uikit "github.com/busdk/bus-ui/pkg/uikit"
)

shell, err := uikit.PageShellChecked(uikit.PageShellProps{
  HeaderNodes: []gx.Node{
    gx.Element("h1", nil, gx.Text("Accounting")),
  },
  MainNodes: []gx.Node{
    gx.Element("p", nil, gx.Text("Module content")),
  },
  FooterNodes: []gx.Node{
    gx.Element("small", nil, gx.Text("Synced")),
  },
})
