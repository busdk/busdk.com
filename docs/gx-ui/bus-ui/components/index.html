Bus UI Components

Shared structure for product surfaces.

These family pages explain the public component APIs one layer at a time. The shared components build gx.Node trees, validate before render, and only use pkg/uikit explicitly when the page is documenting deprecated compatibility only.

Example

The shell family now exports through pkg/ui. Compose the page frame with typed node trees first, then route it through a boundary adapter only if the page is still carrying migration debt. 

import (
  gx "github.com/busdk/bus-gx/pkg/gx"
)

headerNodes := []gx.Node{
  gx.Element("h1", nil, gx.Text("Accounting")),
}

mainNodes := []gx.Node{
  gx.Element("p", nil, gx.Text("Module content")),
}

footerNodes := []gx.Node{
  gx.Element("small", nil, gx.Text("Synced")),
}
