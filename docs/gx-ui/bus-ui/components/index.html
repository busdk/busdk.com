Bus UI Components

Shared structure for product surfaces.

Start with shells and navigation, then add panels, action rows, buttons, status, and empty or loading states. Every checked component returns either safe markup or a clear validation error.

Core families

FamilyUse it forPrimary names
ShellsApplication frames, module pages, sidebar layouts, split surfaces.AppShellChecked, PageShellChecked, SidebarShellChecked, SplitLayoutChecked
NavigationTabs, menus, side navigation, section switching.TabsChecked, SidebarNavChecked, MenuChecked
ControlsButtons, icon buttons, links, grouped actions.ButtonChecked, LinkButtonChecked, EventBarChecked
StatusSimple state, progress, empty screens, recoverable errors.StatusPillChecked, LoadingStateChecked, EmptyStateChecked, ErrorBannerChecked

Example

shell, err := uikit.AppShellChecked(uikit.AppShellProps{
  Title: "Accounting",
  NavHTML: uikit.Tabs(uikit.TabsProps{
    Active: "files",
    Items: []uikit.TabItem{
      {ID: "overview", Label: "Overview", Href: "/modules/accounting/"},
      {ID: "files", Label: "Files", Href: "/modules/accounting/files"},
    },
  }),
  BodyHTML: pageHTML,
})
