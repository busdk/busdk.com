TextTable is the compatibility path for trusted row HTML.

Use it when the headers are static and the row nodes already come from another checked helper. It keeps the old string-or-node table shape alive while validation stays explicit.

Checked API

TextTableChecked(headers []string, rows []Node, log ControlLogSink) (Node, error)

The inputs are static headers and trusted row Node values. The result is a rendered Node.

When to use it

Use TextTable for legacy or compatibility callers that already own row markup. If you want cell-level validation and generated row objects, use DenseTable instead.

Example

import uikit "github.com/busdk/bus-ui/pkg/uikit"

rows := []uikit.Node{
  uikit.Node("June receipts3 filesReady"),
}

table, err := uikit.TextTableChecked([]string{"Title", "Files", "State"}, rows, nil)

This checkout does not expose a matching pkg/ui wrapper yet, so the example uses pkg/uikit directly.
