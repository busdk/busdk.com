Bus UI Data Display

Readable data surfaces from checked Go props.

Use table primitives for comparable rows, record primitives for projected objects, and status primitives for result and error states.

Display families

FamilyUse it forNames
TablesDense comparable rows or text-only table output.DenseTableChecked, TextTableChecked
RecordsTitle, metadata, detail, badge, and action lists.RecordListChecked, SummaryItemChecked
ProjectionProvider fields, public error summaries, and structured detail.ProjectionDetailChecked, ProviderErrorChecked
StatusResult panels and error banners.ResultPanelChecked, ErrorBannerChecked
Media and historyTime-ordered activity and compact image sets.TimelineChecked, ImageGalleryChecked

Example

import uikit "github.com/busdk/bus-ui/pkg/uikit"

records, err := uikit.RecordListChecked(uikit.RecordListProps{
  Items: []uikit.SummaryItemProps{
    {
      Title:    "June receipts",
      Metadata: "3 files",
      Detail:   "Prepared for accounting review.",
      Badge:    "Ready",
    },
  },
})

The pkg/ui facade covers the core checked component set. Data display remains on pkg/uikit for now while those wrappers are promoted.
