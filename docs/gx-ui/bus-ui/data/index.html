Bus UI Data Display

Readable data surfaces from checked Go props.

Use the individual concept pages for checked table, record, projection, status, and timeline helpers. Each page names the exact Go entry point and the return type.

Concept pages

PageUse it forChecked API
DenseTableDense comparable rows with validated headings and cell counts.DenseTableChecked(p DenseTableProps) (Node, error)
TextTableCompatibility tables that already own trusted row nodes.TextTableChecked(headers []string, rows []Node, log ControlLogSink) (Node, error)
RecordListOrdered record summaries with empty-state support.RecordListChecked(p RecordListProps) (string, error)
SummaryItemCompact summary cards and list items.SummaryItemChecked(p SummaryItemProps) (string, error)
ProjectionDetailPublic-safe projection fields plus evidence actions and diagnostics.ProjectionDetailChecked(p ProjectionDetailProps) (ProjectionDetailResult, error)
ProviderErrorPublic provider failure surfaces and redacted field errors.ProviderErrorChecked(p ProviderErrorProps) (string, error)
TimelineOrdered event history with timestamps, sequences, and status chips.TimelineChecked(p TimelineProps) (string, error)

Shared example

import uikit "github.com/busdk/bus-ui/pkg/uikit"

rows := []uikit.DenseTableRow{
  uikit.DenseTableRowText("June receipts", "3 files", "Ready"),
}

table, err := uikit.DenseTableChecked(uikit.DenseTableProps{
  Caption: "Document queue",
  Columns: []uikit.DenseTableColumn{
    uikit.DenseTableColumnText("title", "Title"),
    uikit.DenseTableColumnText("files", "Files"),
    uikit.DenseTableColumnText("state", "State"),
  },
  Rows: rows,
})

This checkout does not expose a matching pkg/ui wrapper yet, so the examples use pkg/uikit directly until that migration lands.
