Bus UI Evidence

EvidenceURLResolver keeps links policy-driven.

Use the resolver when evidence components need an open or download URL but the product host owns storage layout, authorization, and allowed public paths.

Public API

Packagegithub.com/busdk/bus-ui/pkg/ui
PropsEvidenceURLResolverProps
ResolverEvidenceURLResolver
ResolveResolveEvidenceURL

Example

href, err := ui.ResolveEvidenceURL(ui.EvidenceURLResolverProps{
  BaseURL: "/modules/accounting/evidence/",
  Path:    "receipt-42.pdf",
})
