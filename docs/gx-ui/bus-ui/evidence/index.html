Bus UI Evidence And Files

Evidence UI without leaking storage policy.

Use the individual evidence pages for safe links, inline previews, and image galleries. The checked APIs keep URL policy and preview fallbacks explicit.

Concept pages

PageUse it forChecked API
UploadFile selection and drop affordances.FileInputChecked, DropZoneChecked
EvidenceLinkSafe open/download links with disabled states.EvidenceLinkChecked(p EvidenceLinkProps) (string, error)
EvidencePreviewInline previews or fallback panels when embedding is blocked.EvidencePreviewChecked(p EvidencePreviewProps) (string, error)
ImageGalleryAllowlisted image sets with per-item diagnostics.ImageGalleryChecked(p ImageGalleryProps) (ImageGalleryResult, error)
URL policyNormalize public URLs and block unsafe or unavailable links.evidence URL helpers

Shared example

import uikit "github.com/busdk/bus-ui/pkg/uikit"

preview, err := uikit.EvidencePreviewChecked(uikit.EvidencePreviewProps{
  Title:       "Bank statement",
  PreviewURL:  "/modules/accounting/evidence/bank-statement.pdf",
  OpenURL:     "/modules/accounting/evidence/bank-statement.pdf",
  ContentType: "application/pdf",
  Fallback:    "Preview is unavailable.",
})

This checkout does not expose a matching pkg/ui wrapper yet, so the examples use pkg/uikit directly until that migration lands.
