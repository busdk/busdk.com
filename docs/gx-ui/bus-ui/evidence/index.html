Bus UI Evidence And Files

Evidence UI without leaking storage policy.

Evidence primitives render upload controls, safe links, and previews. The module owns access checks, storage URLs, provider credentials, and download policy.

Evidence pieces

PieceUse it forNames
UploadFile selection and drop affordances.FileInputChecked, DropZoneChecked
LinksSafe evidence links with disabled states and labels.EvidenceLinkChecked
PreviewInline evidence summaries and preview metadata.EvidencePreviewChecked
URL policyNormalize public URLs and block unsafe or unavailable links.evidence URL helpers

Example

preview, err := uikit.EvidencePreviewChecked(uikit.EvidencePreviewProps{
  Title: "Bank statement",
  Items: []uikit.EvidenceLinkProps{
    {
      Label: "Open PDF",
      Href:  "/modules/accounting/evidence/bank-statement.pdf",
    },
  },
})
