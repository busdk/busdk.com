Bus UI Assistant

AIThreadList keeps thread navigation explicit.

Use it when the assistant surface needs a dedicated thread chooser with optional archive actions and an active row marker.

Checked API

AIThreadListChecked(p AIThreadListProps) (string, error)

When to use it

Use AIThreadList for sidebars, split workbenches, or thread pickers that need explicit selection and archive affordances.

Key props

Threads, ActiveThread, OnSelect, OnArchive, and Attrs.

Example

import assistantui "github.com/busdk/bus-ui/pkg/assistantui"

html, err := assistantui.AIThreadListChecked(assistantui.AIThreadListProps{
  Threads: []assistantui.AIThreadSummary{{ID: "thread-1", Title: "Draft review"}},
})
