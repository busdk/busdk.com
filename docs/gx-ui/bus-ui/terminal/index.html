Bus UI Terminal

Terminal surfaces are split into focused concept pages.

Use these pages for the session panel, output stream, input box, approval prompt, and the adapter/session-view layer that projects terminal events into renderable state. Preferred public import path: github.com/busdk/bus-ui/pkg/terminalui; pkg/uikit remains compatibility-only for legacy callers.

Concept pages

PageUse it forChecked API
TerminalSessionPanelTerminal session chrome, command context, output, and session status.TerminalSessionPanelChecked(props TerminalSessionPanelProps) (string, error)
TerminalOutputViewValidated stdout, stderr, stdin, and system output chunks.TerminalOutputViewChecked(chunks []TerminalChunk, emptyText string, log ControlLogSink) (string, error)
TerminalInputBoxCommand entry, submit state, and exit actions.TerminalInputBoxChecked(props TerminalInputBoxProps) (string, error)
TerminalApprovalPromptPending approval prompts and decision buttons.TerminalApprovalPromptChecked(prompt TerminalApprovalPrompt) (string, error)
TerminalAdaptersTerminal event normalization, session views, and adapter helpers.TerminalSessionAdapter(input TerminalSessionAdapterInput) (TerminalSessionView, Dispose, error)

Example

import terminalui "github.com/busdk/bus-ui/pkg/terminalui"

seq := 1
panel, err := terminalui.TerminalSessionPanelChecked(terminalui.TerminalSessionPanelProps{
  Title:      "Verification",
  Command:    "go test ./...",
  SessionID:  "sess_123",
  State:      terminalui.TerminalSessionStateRunning,
  Output:     []terminalui.TerminalChunk{{Stream: "stdout", Sequence: &seq, Text: "ok"}},
  EmptyOutput: "No output yet.",
})
