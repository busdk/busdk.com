Bus UI Terminal

Session panels and operator IO.

Terminal surfaces keep session layout, command input, streamed output, prompt state, approvals, and running status consistent across Bus products.

Terminal pieces

PieceUse it forNames
Session panelSession chrome, command context, and status framing.TerminalSessionPanelChecked
Output streamStdout and stderr chunks, idle states, and exit feedback.TerminalOutputChecked
Input and approvalsCommand entry, submit states, approval prompts, and action handoff.TerminalInputChecked
AdaptersConnect terminal sources and session metadata to checked rendering.terminal source and adapter helpers

Example

seq1, seq2 := 1, 2
terminal, err := uikit.TerminalSessionPanelChecked(uikit.TerminalSessionPanelProps{
  Title:     "Verification",
  Command:   "go test ./...",
  SessionID: "sess_123",
  State:     uikit.TerminalSessionStateRunning,
  Output: []uikit.TerminalChunk{
    {Stream: "stdout", Sequence: &seq1, Text: "go test ./..."},
    {Stream: "stdout", Sequence: &seq2, Text: "ok"},
  },
})
