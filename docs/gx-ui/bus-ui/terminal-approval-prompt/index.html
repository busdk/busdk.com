Bus UI Terminal

TerminalApprovalPrompt renders approval decisions.

Use it for one blocked terminal action that needs explicit approve or deny decisions with checked prompt validation.

Checked API

TerminalApprovalPromptChecked(prompt TerminalApprovalPrompt) (string, error)

When to use it

Use TerminalApprovalPrompt for terminal flows that require operator consent before the session can continue or exit.

Key props

ID, Title, Summary, Decisions, Pending, Disabled, Attrs, and Log.

Example

import uikit "github.com/busdk/bus-ui/pkg/uikit"

html, err := uikit.TerminalApprovalPromptChecked(uikit.TerminalApprovalPrompt{
  Title:   "Approve command?",
  Summary: "Run go test ./...?",
  Decisions: []uikit.TerminalApprovalDecision{
    {Label: "Approve", Decision: uikit.TerminalApprovalDecisionApprove, RequestID: "req-1", OnClick: func(uikit.TerminalApprovalEvent) uikit.Result { return uikit.Noop() }},
  },
})
