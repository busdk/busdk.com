Bus UI Assistant

Assistant surfaces are split into focused concept pages.

Use these pages for the assistant shell, panel, composer, model chooser, approval flows, review status, thread list, message rendering, markdown, attachments, and thread isolation. Preferred public import path: github.com/busdk/bus-ui/pkg/assistantui; pkg/uikit remains compatibility-only for legacy callers.

Concept pages

PageUse it forChecked API
AssistantShellGeneric business-plus-assistant shell layout with collapsible assistant chrome.AssistantShellChecked(p AssistantShellProps) (string, error)
AIPanelThread lists, messages, approvals, attachments, composer state, and model controls in one panel.AIPanelChecked(p AIPanelProps) (string, error)
AIComposerControlled prompt input with send and interrupt actions.AIComposerChecked(p AIComposerProps) (string, error)
AIModelSelectModel selection or display-only model state.AIModelSelectChecked(p AIModelSelectProps) (string, error)
AIApprovalsPending approval requests with approve and reject controls.AIApprovalsChecked(p AIApprovalsProps) (string, error)
AIReviewStatusReview-before-apply status cards and state summaries.AIReviewStatusChecked(p AIReviewStatusProps) (string, error)
AIThreadIsolationWorkspace, branch, owner, and conflict status for assistant thread isolation.AIThreadIsolationChecked(p AIThreadIsolationProps) (string, error)
AIThreadListSelectable assistant thread lists and archive actions.AIThreadListChecked(p AIThreadListProps) (string, error)
AIMessageValidated transcript bubbles with trusted markdown or escaped text.AIMessageChecked(p AIMessageProps) (string, error)
AIMarkdownSafe markdown rendering with explicit link policy.AIMarkdownChecked(p AIMarkdownProps) (string, error)
AIAttachmentListAttachment chips with open, inspect, and remove actions.AIAttachmentListChecked(p AIAttachmentListProps) (string, error)

Example

import assistantui "github.com/busdk/bus-ui/pkg/assistantui"

panel, err := assistantui.AIPanelChecked(assistantui.AIPanelProps{
  Title:        "Review",
  ActiveThread:  "thread-1",
  Threads:      []assistantui.AIThreadSummary{{ID: "thread-1", Title: "Draft review"}},
  Messages:     []assistantui.AIPanelMessage{{Role: "assistant", Text: "Ready for review."}},
  Draft:        "Check the diff",
  Model:        "gpt-5",
  ModelOptions:  []assistantui.AIModelOption{{ID: "gpt-5", Label: "GPT-5"}},
})
