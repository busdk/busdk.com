Bus UI Assistant

Guided AI workbench surfaces.

Assistant surfaces keep model choice, approvals, review status, thread isolation, composer state, and panel layout consistent across Bus products.

Assistant pieces

PieceUse it forNames
Shell and panelThread layout, workbench chrome, message panels, and assistant framing.AssistantShellChecked, AIPanelChecked
ComposerPrompt entry, attachments, send state, and reply controls.AIComposerChecked
ControlsModel selection, approval prompts, review status, and thread isolation cues.AIModelSelectChecked, AIApprovalsChecked, AIReviewStatusChecked, AIThreadIsolationChecked
AdaptersConnect assistant state to checked rendering.assistant state and adapter helpers

Example

panel, err := uikit.AIPanelChecked(uikit.AIPanelProps{
  Title: "Review",
  BodyHTML: uikit.AIReviewStatus(uikit.AIReviewStatusProps{
    State:   uikit.AIReviewAccepted,
    Message: "Changes accepted by supervisor.",
  }),
})
