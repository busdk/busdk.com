Bus UI Text Area

Multiline text with node-first rows and attributes.

Use the textarea helper when a control needs a larger text box, fixed rows, and the same controlled validation path as the single-line input helpers.

Public surface

FunctionProps typeImport path
TextAreaTextAreaPropsgithub.com/busdk/bus-ui/pkg/ui

When to use it

Use TextArea for notes, descriptions, and longer free-form fields that still need a stable name, label, and safe attributes. This helper is now on pkg/ui, while any pkg/uikit mention is deprecated compatibility only.

See also Field, Input family, and Reference.

Example

import ui "github.com/busdk/bus-ui/pkg/ui"

notes, err := ui.TextArea(ui.TextAreaProps{
  Name:        "notes",
  Value:       "Reviewed by accounting.",
  Placeholder: "Add notes",
  Rows:        4,
})
if err != nil {
  return err
}
