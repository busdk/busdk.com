Bus UI Select

Choice lists with typed options and validation.

Use the select helper when the module needs a controlled dropdown with a stable selected option and the options themselves stay in Go data.

Checked surface

FunctionProps typeImport path
SelectCheckedSelectPropsgithub.com/busdk/bus-ui/pkg/uikit

When to use it

Use SelectChecked when the control should render a finite set of options with one selected value. This helper is still on pkg/uikit while the public facade continues to expand.

See also Field, Form, and Reference.

Example

import uikit "github.com/busdk/bus-ui/pkg/uikit"

selectHTML, err := uikit.SelectChecked(uikit.SelectProps{
  Name:     "status",
  Selected: "ready",
  Options: []uikit.SelectOption{
    {ID: "ready", Label: "Ready"},
    {ID: "blocked", Label: "Blocked"},
  },
})
if err != nil {
  return err
}
