Bus UI Input Family

Single-line controls for text, secrets, and dates.

Use the input family when you need a typed native control with shared validation, stable attributes, and a consistent wrapper for text, password, or date fields.

Checked surface

FunctionProps typeImport path
InputChecked, TextInputCheckedInputProps, TextInputPropsgithub.com/busdk/bus-ui/pkg/ui
PasswordInputChecked, DateInputCheckedstring args plus attrs/loggithub.com/busdk/bus-ui/pkg/uikit

When to use it

Use InputChecked or TextInputChecked for ordinary text entry, PasswordInputChecked for secret values, and DateInputChecked when the field must stay in YYYY-MM-DD form.

The text-input helpers are already on pkg/ui. Password and date helpers still live on pkg/uikit while the facade migration is in flight.

See also Field, Form, and Reference.

Example

import (
  ui "github.com/busdk/bus-ui/pkg/ui"
  uikit "github.com/busdk/bus-ui/pkg/uikit"
)

title, err := ui.TextInputChecked(ui.TextInputProps{
  Name:  "title",
  Value: "Bank statement",
})
if err != nil {
  return err
}

password, err := uikit.PasswordInputChecked(
  "password",
  "",
  "Enter your password",
  "current-password",
  nil,
  nil,
)
if err != nil {
  return err
}

date, err := uikit.DateInputChecked("posting_date", "2026-06-14", nil, nil)
if err != nil {
  return err
}
