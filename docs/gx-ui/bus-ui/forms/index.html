Bus UI Forms

Inputs with explicit boundaries.

Form primitives keep labels, validation text, disabled states, file selection, and submit feedback consistent while the owning module decides routes and policy. The preferred API composes typed gx.Node trees. Any remaining pkg/uikit reference here is migration debt with a deletion path.

Where to start

Use the form page when you need native submit wiring, the field page when you need a labeled control wrapper, and the upload pages when the module owns file intake or drag-and-drop policy. The public facade is on pkg/ui; any pkg/uikit reference here is migration debt with a deletion path.

See also Evidence and files and Reference.

Example

Compose the form from typed child nodes. The node API keeps labels, controls, and validation explicit without falling back to raw HTML slots. 

import (
  gx "github.com/busdk/bus-gx/pkg/gx"
)

formNodes := []gx.Node{
  gx.Element("label", gx.Props{"for": "description"}, gx.Text("Description")),
  gx.Element("input", gx.Props{
    "id":    "description",
    "name":  "description",
    "value": "Bank statement",
    "type":  "text",
  }),
  gx.Element("button", gx.Props{"type": "submit"}, gx.Text("Upload")),
}

During migration, the checked helpers can wrap this node tree, but the public example stays node-first.
