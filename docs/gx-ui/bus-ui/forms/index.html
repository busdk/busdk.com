Bus UI Forms

Inputs with explicit boundaries.

Form primitives keep labels, validation text, disabled states, file selection, and submit feedback consistent while the owning module decides routes and policy.

Form pieces

PieceUse it forNames
Form and fieldMethod, action, field label, help text, and errors.FormChecked, FieldChecked
Input familyText, password, and date controls.InputChecked, TextInputChecked, PasswordInputChecked, DateInputChecked
Text area and selectMultiline text and choice controls.TextAreaChecked, SelectChecked
Submit control and filter toolbarPending states, submit buttons, filters, and reset actions.SubmitControlChecked, FilterToolbarChecked
File input and drop zoneUpload controls and drag/drop affordances.FileInputChecked, DropZoneChecked
Credential login cardUsername and password sign-in cards.CredentialLoginCardChecked

Where to start

Use the form page when you need native submit wiring, the field page when you need a labeled control wrapper, and the upload pages when the module owns file intake or drag-and-drop policy.

The checked helpers already on pkg/ui are the preferred public import path. The rest of the form family still lives on pkg/uikit while those wrappers move over.

See also Evidence and files and Reference.

Example

Compose the form from typed child nodes. The checked facade keeps labels, controls, and validation explicit without falling back to raw HTML slots. 

import (
  gx "github.com/busdk/bus-gx/pkg/gx"
  ui "github.com/busdk/bus-ui/pkg/ui"
)

field, err := ui.FieldNodeChecked(ui.FieldProps{
  Label:       "Description",
  ControlID:   "description",
  ControlName: "description",
  RenderControlNode: func(attrs map[string]string) (gx.Node, error) {
    return ui.TextInputNodeChecked(ui.TextInputProps{
      Name:  "description",
      Value: "Bank statement",
      Attrs: attrs,
    })
  },
})
if err != nil {
  return err
}

submit, err := ui.SubmitControlNodeChecked(ui.SubmitControlProps{
  Label: "Upload",
})
if err != nil {
  return err
}

form, err := ui.FormChecked(ui.FormProps{
  Method: ui.FormMethodPost,
  Action: "/modules/accounting/api/files",
  BodyNodes: []gx.Node{
    field,
    submit,
  },
})
