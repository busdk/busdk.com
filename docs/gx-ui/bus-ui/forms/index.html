Bus UI Forms

Inputs with explicit boundaries.

Form primitives keep labels, validation text, disabled states, file selection, and submit feedback consistent while the owning module decides routes and policy.

Form pieces

PieceUse it forNames
Form and fieldMethod, action, field label, help text, and errors.FormChecked, FieldChecked
Text inputsText, password, date, select, and textarea controls.InputChecked, TextAreaChecked, SelectChecked
FilesUpload controls and drag/drop affordances.FileInputChecked, DropZoneChecked
WorkflowFilters, submit buttons, pending states, and result summaries.FilterToolbarChecked, SubmitControlChecked

Example

form, err := uikit.FormChecked(uikit.FormProps{
  Method: uikit.FormMethodPost,
  Action: "/modules/accounting/api/files",
  BodyHTML: uikit.Field(uikit.FieldProps{
    Label: "Description",
    BodyHTML: uikit.TextInput(uikit.TextInputProps{
      Name:  "description",
      Value: "Bank statement",
    }),
  }) + uikit.FileInput(uikit.FileInputProps{
    Name:      "file",
    AriaLabel: "Evidence file",
  }) + uikit.SubmitControl(uikit.SubmitControlProps{
    Label: "Upload",
  }),
})
