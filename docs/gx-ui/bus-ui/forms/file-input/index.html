Bus UI File Input

A safe file picker input for upload flows.

Use the file input helper when a module needs a controlled native file picker and wants the checked helper to own the accept, multiple, and accessibility wiring.

Checked surface

FunctionProps typeImport path
FileInputCheckedFileInputPropsgithub.com/busdk/bus-ui/pkg/uikit

When to use it

Use FileInputChecked when the host module wants a plain file input without adding drag-and-drop policy. The helper remains on pkg/uikit for now.

See also Drop zone, Evidence and files, and Reference.

Example

import uikit "github.com/busdk/bus-ui/pkg/uikit"

pickerHTML, err := uikit.FileInputChecked(uikit.FileInputProps{
  Name:          "attachment",
  AcceptedTypes: []string{"application/pdf", "image/png"},
  Multiple:      true,
})
if err != nil {
  return err
}
