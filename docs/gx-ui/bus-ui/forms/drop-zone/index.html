Bus UI Drop Zone

Drag-and-drop upload affordances with host-owned policy.

Use the drop zone when the module wants a visible upload target, optional actions, and a checked shell that still leaves storage and authorization policy in the host.

Checked surface

FunctionProps typeImport path
DropZoneCheckedDropZonePropsgithub.com/busdk/bus-ui/pkg/uikit

When to use it

Use DropZoneChecked when a module needs drag-and-drop intake, a friendly title and copy block, and the ability to keep the file picker inside the same shared surface. The helper stays on pkg/uikit for now.

See also File input, Evidence and files, and Reference.

Example

import uikit "github.com/busdk/bus-ui/pkg/uikit"

zoneHTML, err := uikit.DropZoneChecked(uikit.DropZoneProps{
  ID:        "evidence-dropzone",
  Title:     "Upload evidence",
  Copy:      "Drop PDF and image files here.",
  MaxBytes:  10 << 20,
  AcceptedTypes: []string{
    "application/pdf",
    "image/png",
  },
})
if err != nil {
  return err
}
