Bus UI Portal

HostContext is the portal module boundary.

Use HostContext when a reusable portal component needs module identity, base paths, static asset paths, public runtime values, or API URL policy.

Public API

Packagegithub.com/busdk/bus-ui/pkg/uiportal
ContextHostContext, HostContextProvider
ReadHostContextFromProvider
ResolveResolveModuleURL, RuntimeAPIURL

Example

ctx := uiportal.HostContext{
  ModuleID:       "accounting",
  BasePath:       "/modules/accounting/",
  PortalBasePath: "/",
}

moduleURL, err := uiportal.ResolveModuleURL(ctx, "reports")
