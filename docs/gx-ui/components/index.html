Bus UI Tutorial

Compose public UI from Go APIs.

bus-ui provides reusable component families with deterministic markup, explicit validation errors, stable CSS hooks, and node-first public helpers. HTML adapters are explicit render-boundary helpers; new product code composes typed nodes first.

Render a form with node-first inputs

Compose the form from typed child nodes. The public helpers keep labels, controls, and validation explicit without falling back to raw HTML slots. 

import (
  gx "github.com/busdk/bus-gx/pkg/gx"
  ui "github.com/busdk/bus-ui/pkg/ui"
)

field, err := ui.Field(ui.FieldProps{
  Label: "Description",
  RenderControlNode: func(attrs map[string]string) (gx.Node, error) {
    return ui.Input(ui.InputProps{
      Name:  "description",
      Value: "Bank statement",
      Attrs: attrs,
    })
  },
})
if err != nil {
  return err
}

submit, err := ui.SubmitControl(ui.SubmitControlProps{
  Label: "Upload",
})
if err != nil {
  return err
}

node, err := ui.Form(ui.FormProps{
  Method: ui.FormMethodPost,
  Action: "/modules/accounting/api/files",
  BodyNodes: []gx.Node{
    field,
    submit,
  },
})
if err != nil {
  return err
}

html, err := gx.RenderHTML(node)

Show status and results

Status surfaces use semantic states and public-safe text. Result panels can include recovery controls without taking ownership of the provider call. 

import (
  gx "github.com/busdk/bus-gx/pkg/gx"
  ui "github.com/busdk/bus-ui/pkg/ui"
)

node, err := ui.ResultPanel(ui.ResultPanelProps{
  Title:   "Evidence pack ready",
  Status:  ui.StatusSuccess,
  Summary: "3 files prepared for review.",
  Events: []ui.EventBarAction{
    {
      Label:   "Open pack",
      Variant: ui.ButtonPrimary,
      Control: ui.ControlProps{Action: "open-pack"},
    },
  },
})

html, err := gx.RenderHTML(node)

Display records and tables

Use native tables for dense comparable data and record lists for non-tabular projected objects. Summary items provide a compact title, metadata, detail, and badge contract. 

import (
  gx "github.com/busdk/bus-gx/pkg/gx"
  ui "github.com/busdk/bus-ui/pkg/ui"
)

node := ui.DenseTable(ui.DenseTableProps{
  Caption: "Invoices",
  Columns: []ui.DenseTableColumn{
    ui.DenseTableColumnText("date", "Date"),
    ui.DenseTableColumnText("total", "Total"),
  },
  Rows: []ui.DenseTableRow{
    ui.DenseTableRowText("2026-06-12", "128.40 EUR"),
  },
})

html, err := gx.RenderHTML(node)

Keep policy out of components

Node-first components validate their public rendering contracts. Product modules still own authorization, route selection, upload endpoints, provider calls, business state transitions, and redaction policy.

New work should use typed gx.Node composition and the public pkg/ui API, rendering to HTML only at the boundary.
