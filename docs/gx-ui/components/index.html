Bus UI Tutorial

Compose checked UI from Go APIs.

bus-ui provides reusable component families with deterministic markup, explicit validation errors, stable CSS hooks, and compatibility wrappers for existing Go presenters.

Component families

Family Use it for Examples
Shells and navigation App shells, page shells, panels, sidebars, tabs, menus, split layouts. AppShellChecked, PageShellChecked, TabsChecked
Controls and forms Buttons, icon buttons, event bars, semantic forms, fields, filters, submit states. EventBarChecked, FormChecked, SubmitControlChecked
Data display Status, errors, tables, records, summaries, projections, timelines, galleries. ResultPanelChecked, DenseTableChecked, RecordListChecked
Files and evidence File inputs, drop zones, safe evidence links, inline previews, URL policy checks. FileInputChecked, DropZoneChecked, EvidencePreviewChecked
AI and terminal Assistant shells, model selection, approvals, review state, terminal IO, session panels. AIModelSelectChecked, AIApprovalsChecked, TerminalSessionPanelChecked

Render a form with checked inputs

Generic inputs reject unsafe shapes, while file input has its own wrapper so browser file access and upload policy stay outside the generic text-input path. 

form, err := uikit.FormChecked(uikit.FormProps{
  Method: uikit.FormMethodPost,
  Action: "/modules/accounting/api/files",
  BodyHTML: uikit.Field(uikit.FieldProps{
    Label: "Description",
    BodyHTML: uikit.TextInput(uikit.TextInputProps{
      Name:  "description",
      Value: "Bank statement",
    }),
  }) + uikit.FileInput(uikit.FileInputProps{
    Name:          "file",
    AriaLabel:     "Evidence file",
    AcceptedTypes: []string{"application/pdf", "image/png"},
  }),
})

Show status and results

Status surfaces use semantic states and public-safe text. Result panels can include recovery controls without taking ownership of the provider call. 

html, err := uikit.ResultPanelChecked(uikit.ResultPanelProps{
  Title:   "Evidence pack ready",
  Status:  uikit.StatusSuccess,
  Summary: "3 files prepared for review.",
  Events: []uikit.EventBarAction{
    {
      Label:   "Open pack",
      Variant: uikit.ButtonPrimary,
      Control: uikit.ControlProps{Action: "open-pack"},
    },
  },
})

Display records and tables

Use native tables for dense comparable data and record lists for non-tabular projected objects. Summary items provide a compact title, metadata, detail, and badge contract. 

table, err := uikit.DenseTableChecked(uikit.DenseTableProps{
  Caption: "Invoices",
  Columns: []uikit.DenseTableColumn{
    uikit.DenseTableColumnText("date", "Date"),
    uikit.DenseTableColumnText("total", "Total"),
  },
  Rows: []uikit.DenseTableRow{
    uikit.DenseTableRowText("2026-06-12", "128.40 EUR"),
  },
})

Keep policy out of components

Checked components validate their public rendering contracts. Product modules still own authorization, route selection, upload endpoints, provider calls, business state transitions, and redaction policy.
