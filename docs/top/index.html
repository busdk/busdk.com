Bus Top

Understand what your machine is doing.

Bus Top is a friendly local process monitor that groups related processes, shows deterministic system facts, and can add privacy-aware AI explanations when you want plain-language help.

Read docs Discuss monitoring

What it is for

Bus Top is for developers, operators, technical founders, and power users who want a calmer local view of processes, helpers, servers, agents, language servers, runtime workers, and resource spikes.

Core workflows

  • Open a live process and system pressure view.
  • Group repeated helpers into process families.
  • Export deterministic JSON snapshots for support and automation.
  • Use optional privacy-redacted AI explanations and host diagnosis when configured.

Modules behind the product

The product is centered on bus-top. bus-status supports status/readiness workflows and cross-links where it helps the operator.
