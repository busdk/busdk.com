Bus Top

Modules behind the local process monitor.

Bus Top is intentionally small as a product line. It should stay focused on helping users understand local process activity and system pressure.

Core product modules

  • bus-top for live views, process-family grouping, snapshots, and host diagnosis.
  • bus-status where readiness and status views help the operator.
  • Optional AI Platform hooks for redacted explanations when configured.
