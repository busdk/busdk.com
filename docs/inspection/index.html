Bus Inspection

Local inspection reports and action lists.

Bus Inspection helps inspection teams manage sites, observations, photos, customer acknowledgements, generated reports, and action-list follow-up in one local BusDK workspace.

Read docs Request a pilot

What it is for

This product is for recurring technical and site inspection work where teams need auditable reports, customer-visible action tracking, photo evidence, and controlled access without scattering records across spreadsheets, folders, and email.

Core workflows

  • Manage customers, sites, contacts, report packages, users, and site access.
  • Record inspections with previous-value comparison, observations, and photos.
  • Let customers comment on and acknowledge their own findings.
  • Generate PDF/DOCX reports and action-list exports from versioned snapshots.

Modules behind the product

The main product module is bus-inspection, supported by Bus gateway, Bus UI, workspace data, document/export infrastructure, and AI Platform capabilities when assisted configuration needs a model adapter.
