Bus Inspection

Modules behind the inspection product.

Bus Inspection is the public product. Supporting Bus modules provide login, UI, workspace data, document output, and optional assisted configuration.

Core product modules

  • bus-inspection for sites, observations, reports, photos, acknowledgements, and action lists.
  • Gateway and auth surfaces for role-scoped customer and operator access.
  • Bus UI, workspace data, file, document, PDF, and export infrastructure.
  • AI Platform adapters when model-assisted setup is configured.
