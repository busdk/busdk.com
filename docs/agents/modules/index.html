Bus Agentic Development

Modules behind the agentic development product.

The public product is the whole supervised agentic development loop. These modules are evidence for technical evaluators, not separate marketing products.

Core product modules

  • bus-task and task threads for durable work state.
  • bus-worker for worker creation, dispatch, control, and review evidence.
  • bus-agent-runtime for lightweight Bus-owned agent execution.
  • bus-repos, remotes, notes, chat, prompts, run workflows, and terminal state.
  • bus-mcp for capability exposure to local and remote agent tools.

Evaluator path

Start with the product overview, then use the docs to inspect command behavior, workspace data, approvals, and review boundaries.
