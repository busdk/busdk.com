Bus Agentic Development

Semi-autonomous software development with autonomous agents.

Bus Agentic Development gives AI supervisor agents and worker agents durable tasks, repository workspaces, terminals, notes, reviews, MCP capability exposure, and local or SSH-accessible development environments.

Read docs Book a technical demo

What it is for

This product is for teams that want AI agents to do real software work in parallel without losing task state, evidence, terminal output, review decisions, or project memory. The first public focus is BusDK-style software development, especially Go-heavy systems and BusDK module work.

Core workflows

  • Create durable task threads and launch worker agents.
  • Add local or SSH-accessible machines as development capacity.
  • Keep notes, diffs, logs, terminal state, and review evidence attached to work.
  • Use supervisor agents and human approval where the risk calls for it.

Modules behind the product

The product brings together tasks, workers, Bus Agent Runtime, run/prompt workflows, chat, development tooling, remotes, repository workspaces, MCP, notes, and the AI portal surface.
