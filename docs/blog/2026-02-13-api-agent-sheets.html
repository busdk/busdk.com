BusDK Update

Paikallinen API ja taulukkonäkymä tulivat mukaan BusDK:hon

13.2.2026 BusDK sai kaksi näkyvää uutta käyttöpintaa: paikallisen REST-rajapinnan ja selainpohjaisen taulukkonäkymän.

Samassa muutoksessa mukaan tulivat myös agentti- ja asetuspinnat, mutta päivän selvin käyttäjälle näkyvä muutos oli se, että workspacea pystyi nyt käyttämään muutakin kautta kuin suoraan komentoriviltä.

13.2.2026 bus-api bus-sheets Selainpinta

Tiiviisti

TL;DR

  • BusDK sai paikallisen API:n workspace-datalle.
  • BusDK sai taulukkomuotoisen web-käyttöliittymän saman datan selaamiseen.
  • Agentti- ja asetuspinnat tulivat mukaan samaan kokonaisuuteen.

Tämä näkyi heti uusina komentoina. bus api --help kertoi nyt paikallisesta JSON-rajapinnasta, ja bus sheets --help omasta spreadsheet-tyylisestä web-käyttöliittymästä: 

bus api --help
bus sheets --help
bus-api — local REST JSON API gateway for BusDK workspaces.
Commands:
  serve
  openapi

bus-sheets — local spreadsheet-style web UI for BusDK workspaces.
Subcommands:
  serve (default)
  version

Tämä oli käytännössä iso askel, koska sama workspace alkoi avautua sekä ohjelmalliseen käyttöön että selaimessa tehtävään tarkasteluun. Jos halusi rakentaa integraation, bus-api tarjosi siihen lähtöpinnan. Jos taas halusi nähdä samat tiedot taulukkona, bus-sheets avasi siihen oman paikallisen näkymän. Tarkemmat komennot löytyvät bus-api-dokumentaatiosta ja bus-sheets-dokumentaatiosta.

Samalle päivälle osui myös agentti-, preferences- ja config-moduulien lisääminen. Ne eivät olleet yhtä näyttäviä kuin uusi API tai selainnäkymä, mutta ne tekivät samasta suunnasta pysyvämmän: BusDK ei ollut enää vain joukko komentoja, vaan kokonaisuus, jonka ympärille pystyi rakentamaan asetuksia, automaatiota ja käyttöliittymiä.
