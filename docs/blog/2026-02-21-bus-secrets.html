bus-secrets tuo salaisuuksille oman Bus-komennon

21.2.2026 BusDK saa oman työkalun nimetyille salaisuuksille. Sen tarkoitus on erottaa salaiset arvot itse komennoista ja asetuksista niin, että työnkulut voivat viitata salaisuuksiin nimellä.

21.2.2026 bus-secrets SOPS Salaisuudet

Tiiviisti

TL;DR

  • Salaisuudet saavat oman komentopinnan.
  • Repositoryn salaisuuksien alustus, nimeäminen ja listaus siirtyvät samaan työkaluun.
  • Työnkulut voivat viitata arvoihin muodossa secret:nimi.

Uusi pinta näkyy sekä helpissä että ensimmäisessä käyttöönotossa: 

bus-secrets --help

bus-secrets -C busdk.com/tmp/secrets-local-demo init
bus-secrets -C busdk.com/tmp/secrets-local-demo set smoke.test value --scope repo
bus-secrets -C busdk.com/tmp/secrets-local-demo list --scope repo
Commands:
  init
  doctor
  set
  get
  list
  resolve

setup complete
smoke.test

Käytännön hyöty on se, että työnkulut voivat viitata salaisuuteen nimellä sen sijaan että avain kirjoitettaisiin suoraan komentoihin. Tämä helpottaa etenkin bus-dev- ja bus-run-työnkulkuja. Tarkempi syntaksi löytyy bus-secrets-dokumentaatiosta.
