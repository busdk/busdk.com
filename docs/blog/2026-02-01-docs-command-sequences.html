BusDK Update

Loppukäyttäjädokumentaatio siirtyy yleisistä vaiheista oikeisiin bus-komentoketjuihin

1.2.2026 docsit alkavat näyttää arjen työnkulut konkreettisina bus-komentoina eikä vain yleisinä vaihekuvauksina.

Samalla periodihakemistoihin perustuva data-asettelu ja bus validate tulevat näkyväksi osaksi normaalia käyttöä.

1.2.2026DokumentaatioKomennotPeriodihakemistot

Tiiviisti

TL;DR

  • Workflow-docsit alkavat näyttää oikeita bus-komentoja.
  • Periodihakemistot ja indeksitaulut tarkentuvat dokumentoiduksi perusmalliksi.
  • bus validate nousee näkyväksi osaksi normaalia työskentelyä.

Muutos näkyy esimerkiksi siinä, että moduulisivu kertoo nyt suoraan:

Run `bus validate` … and use `--help` for
available subcommands and arguments.

Merkitys on käytännöllinen. Dokumentaatio alkaa kuvata BusDK:n käyttöä konkreettisina komentoina ja niiden ketjuina. Samalla periodipohjainen hakemistorakenne tarkentuu: aineisto järjestyy vuosittain ja jaksoittain eikä vain irrallisiksi CSV-tiedostoiksi.

Docsit kertovat nyt selvemmin, mitä komentoa ajetaan missä vaiheessa ja millaista tiedostorakennetta työtilalta odotetaan.
