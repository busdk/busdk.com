Muistiotositerivit saavat omat selitteensä

bus memo add osaa nyt ottaa debit- ja credit-riveille omat selitteet. Yhteinen muistiotositteen kuvaus voi kertoa kokonaisuuden, ja yksittäiset rivit voivat samalla kertoa mitä juuri niillä oikaistaan.

Sama syntaksi näkyy nyt myös suoraan komennon omassa helpissä, joten ominaisuus ei jää pelkäksi README-esimerkiksi.

6.4.2026bus-memoRiviselitteetHelp

Tiiviisti

TL;DR

  • bus memo add hyväksyy nyt debit- ja credit-riveille muodon ACCOUNT=AMOUNT=ROW_DESCRIPTION.
  • bus memo add --help näyttää saman syntaksin näkyvästi omassa usage-tekstissään.
  • Muistiotosite tulostaa edelleen normaalisti näkyvän MU-*-tositenumeron onnistuneen ajon jälkeen.

Help kertoo uuden riviselitesyntaksin nyt suoraan:

$ bus memo add --help
Usage:
  bus-memo add --date YYYY-MM-DD --desc TEXT --debit ACCOUNT=AMOUNT --credit ACCOUNT=AMOUNT [flags]
  bus-memo add --date YYYY-MM-DD --desc TEXT --debit ACCOUNT=AMOUNT=ROW_DESCRIPTION --credit ACCOUNT=AMOUNT=ROW_DESCRIPTION [flags]

Flags:
  --debit ACCOUNT=AMOUNT[=ROW_DESCRIPTION]
  --credit ACCOUNT=AMOUNT[=ROW_DESCRIPTION]

Muutos on hyödyllinen erityisesti oikaisuissa ja avauskorjauksissa, joissa yksi yhteinen selite ei riitä kertomaan mitä debit- ja credit-rivi tekevät erikseen. Esimerkiksi tällainen kirjaus antaa kummallekin riville oman kuvauksensa:

$ bus memo add \
  --date 2025-01-10 \
  --desc "Opening balance correction" \
  --debit '2200=3.90=Counter-entry for verified bank-opening corrections' \
  --credit '1910=3.90=Correct OP Päätili / ...846 opening'
MU-2

MU-2 pysyy edelleen näkyvänä muistiotositenumerona, ja yksittäiset rivit säilyttävät nyt oman selitteensä tavallisessa päiväkirjassa. Nykyinen käyttö löytyy bus-memon dokumentaatiosta.
