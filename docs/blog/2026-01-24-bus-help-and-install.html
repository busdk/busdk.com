bus sai asennustavan ja alkoi listata löydetyt alikomennot

Myöhemmin samana päivänä bus lakkasi olemasta vain ydinkoodi ja sai ensimmäisen oikean käyttöönotto- ja help-pinnan.

Makefile toi rakentamisen ja asennuksen yhteen paikkaan, ja help alkoi näyttää mitä bus-...-työkaluja ympäristöstä löytyi.

24.1.2026busAsennusHelp

Tiiviisti

TL;DR

  • make install tuli viralliseksi tavaksi asentaa bus.
  • README sai ensimmäiset varsinaiset asennus- ja käyttöohjeet.
  • Help alkoi näyttää löydetyt alikomennot pelkän käyttövirheen sijaan.

Saman päivän näkyvä muutos oli se, että bus sai ensi kertaa dokumentoidun asennustavan:

make install PREFIX="$HOME/.local"
installed .../bin/bus
ensure .../bin is on your PATH

Tämä teki komentopinnasta heti käytännöllisemmän. Samalla help alkoi listata ympäristöstä löytyvät bus-...-alikomennot, mikä teki moduulikokonaisuuden ideasta näkyvän myös ilman lähdekoodin lukemista. Päivän aikana syntyivät siis sekä yhteinen ajomalli että ensimmäinen tapa asentaa ja käyttää sitä.

Jos haluat nähdä nykyisen bus-komennon dokumentaation laajempana, jatka julkiseen bus-repositorioon.
