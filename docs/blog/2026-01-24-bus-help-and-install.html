BusDK Update

bus saa asennustavan ja alkaa listata löydetyt alikomennot

bus saa ensimmäisen oikean käyttöönotto- ja help-pinnan. Asennus voidaan dokumentoida yhdellä komennolla, ja help näyttää mitä bus-...-työkaluja ympäristöstä löytyy.

Komentopinnan voi nyt ottaa käyttöön ilman lähdekoodin lukemista tai askeleiden päättelyä itse.

24.1.2026busAsennusHelp

Tiiviisti

TL;DR

  • make install tulee viralliseksi tavaksi asentaa bus.
  • README saa ensimmäiset varsinaiset asennus- ja käyttöohjeet.
  • Help listaa löydetyt alikomennot pelkän käyttövirheen sijaan.

Dokumentoitu asennustapa näyttää tältä:

$ make install PREFIX="$HOME/.local"
installed .../bin/bus
ensure .../bin is on your PATH

Asennuspolku muuttuu heti käytännöllisemmäksi. Help listaa samalla ympäristöstä löytyvät bus-...-alikomennot, joten moduulikokonaisuuden idea näkyy myös ilman lähdekoodin lukemista. Päivän aikana syntyvät sekä yhteinen ajomalli että ensimmäinen tapa asentaa ja käyttää sitä.

Nykyinen bus-komennon dokumentaatio löytyy julkisesta bus-repositoriosta.
