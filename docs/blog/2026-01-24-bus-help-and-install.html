bus saa asennustavan ja alkaa listata löydetyt alikomennot

Myöhemmin samana päivänä bus lakkaa olemasta vain ydinkoodi ja saa ensimmäisen oikean käyttöönotto- ja help-pinnan.

Makefile tuo rakentamisen ja asennuksen yhteen paikkaan, ja help alkaa näyttää mitä bus-...-työkaluja ympäristöstä löytyy.

24.1.2026busAsennusHelp

Tiiviisti

TL;DR

  • make install tulee viralliseksi tavaksi asentaa bus.
  • README saa ensimmäiset varsinaiset asennus- ja käyttöohjeet.
  • Help alkaa näyttää löydetyt alikomennot pelkän käyttövirheen sijaan.

Saman päivän näkyvä muutos on se, että bus saa ensi kertaa dokumentoidun asennustavan:

make install PREFIX="$HOME/.local"
installed .../bin/bus
ensure .../bin is on your PATH

Tämä tekee komentopinnasta heti käytännöllisemmän. Samalla help alkaa listata ympäristöstä löytyvät bus-...-alikomennot, mikä tekee moduulikokonaisuuden ideasta näkyvän myös ilman lähdekoodin lukemista. Päivän aikana syntyvät siis sekä yhteinen ajomalli että ensimmäinen tapa asentaa ja käyttää sitä.

Jos haluat nähdä nykyisen bus-komennon dokumentaation laajempana, jatka julkiseen bus-repositorioon.
