Gateway saa palvelu- ja käyttäjähallinnan komentopinnan

Gatewayn palveluluettelo, käyttäjät ja näkyvät työkalut saavat oman komentopinnan. Selainympäristön hallinta ei jää enää piiloon vain web-käyttöliittymän taakse.

21.3.2026 bus-gateway Palveluluettelo Käyttäjät

Tiiviisti

TL;DR

  • Selainmoduulien sisäänkäynti tulee näkyväksi komentopinnaksi.
  • Palvelut ja käyttäjät pystyy listaamaan ja muuttamaan suoraan.
  • Gateway sitoo portalin, inspectionin ja muut selainpinnat yhteen.

Uusi komentopinta näkyy jo helpissä:

$ bus gateway --help
Commands:
  serve
  service
  settings
  user

Tyhjässä työtilassa gateway osaa jo listata oletuspalvelut suoraan:

$ bus gateway -C ./workspace service list
id	title	enabled	command	root_mode	root_flag	args
bus-factory	Factory	true	bus-factory	root-flag	--root	
bus-inspection	Inspection	true	bus-inspection	chdir		
bus-ledger	Ledger	true	bus-ledger	chdir		
bus-portal	Portal	true	bus-portal	chdir

Samasta komentopinnasta voi lisätä käyttäjän, rajata hänelle näkyvät palvelut ja asettaa työtilan kirjautumissivun tekstin. Käytännössä gatewaysta tulee työtilan oma hallintakerros selainpalveluille: samat rivit kertovat mitä työkaluja työtila tarjoaa ja kenelle ne ovat näkyvissä. Tarkemmat komennot löytyvät bus-gateway-dokumentaatiosta.
