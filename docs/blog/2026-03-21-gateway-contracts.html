Gateway sai palvelu- ja käyttäjähallinnan komentopinnan

Paikallinen selainympäristö ei enää jäänyt epämääräiseksi taustapalveluksi. bus-gateway sai komennot palvelulistojen, käyttäjien ja näkyvien työkalujen hallintaan.

21.3.2026 bus-gateway Service catalog Users

Tiiviisti

TL;DR

  • Merkitys: selainmoduulit kuten portal ja inspection saivat hallitun sisäänkäynnin.
  • Käyttö: bus-gateway hallitsee palveluluetteloa ja käyttäjien näkyviä työkaluja.
  • Rakenne: asetukset pysyvät workspace-kohtaisina eikä erillistä keskitettyä identiteettipalvelua tarvita.

Konkreettisin muutos on se, että gatewayn selaimessa näkyvä palveluluettelo ja käyttäjät ovat nyt hallittavissa suoraan komentoriviltä. Kun workspaceen lisätään palvelu ja käyttäjä, niiden tulos näkyy heti taulukkotulosteessa: 

bus-gateway service list
bus-gateway user get demo
id             title       enabled  command         root_mode
bus-factory    Factory     true     bus-factory     root-flag
bus-inspection Inspection  true     bus-inspection  chdir
bus-ledger     Ledger      true     bus-ledger      chdir
bus-portal     Portal      true     bus-portal      chdir

username  full_name  role   available_services
demo      Demo User  admin  bus-factory,bus-inspection,bus-ledger,bus-portal

Tämä tekee gatewaysta enemmän kuin pelkän välityspalvelimen. Se on paikallinen hallintakerros, joka määrää mitä selaintyökaluja workspace tarjoaa ja kenelle ne näkyvät. Samalla siitä tuli selkeä jatkumo bus-portal- ja bus-inspection-moduuleille, joille tarvittiin yhteinen kirjautumis- ja käynnistysmalli.
