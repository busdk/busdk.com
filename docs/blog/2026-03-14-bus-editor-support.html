.bus-tiedostoille tulee editorituki

BusDK paketoi 14.3.2026 oman editorituen .bus-tiedostoille. Tärkein käytännön muutos on VS Code -yhteensopiva .vsix-paketti, jonka voi asentaa suoraan editoriin.

Sama julkaisu avaa samalla myös Tree-sitter- ja stdio-kielipalvelinpolut niille editoreille, jotka eivät käytä VS Code -laajennuksia.

14.3.2026busEditorituki.vsix

Tiiviisti

TL;DR

  • .bus-kielipaketin voi paketoida omaksi .vsix-artefaktikseen.
  • Syntax highlighting ja semanttiset tokenit eivät jää enää vain käsin tehtyjen editoriasetusten varaan.
  • Sama pohja tukee myös Tree-sitteriä ja kevyttä kielipalvelinta.

Asennuspolku on suora:

make package-vscode-extension
make check-vscode-extension-release

Tämän jälkeen BusDK:n kielituki voidaan jakaa yhtenä asennettavana artefaktina eikä pelkkänä lähdekoodihakemistona. Muutos on hyödyllinen etenkin silloin, kun .bus-tiedostoista alkaa tulla oikeita käyttöön meneviä työnkulkuja eikä vain kokeellisia skriptejä. Nykyiset asennus- ja editoriohjeet löytyvät editorituen dokumentaatiosta.
