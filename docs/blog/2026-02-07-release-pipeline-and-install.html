BusDK Update

BusDK saa ensimmäisen suoran asennuspolun julkaistusta versiosta

BusDK:n julkaisu alkaa sisältää kaiken olennaisen valmiiseen asennukseen: paketoidut binäärit, tarkistussummat ja install.sh-skriptin.

Nopea asennus nostetaan näkyvästi esiin, joten BusDK:n voi ottaa käyttöön myös suoraan julkaistusta versiosta.

7.2.2026 Suora asennus Julkaistu versio Nopea asennus

Tiiviisti

TL;DR

  • Julkaisu alkaa sisältää asennusskriptin, paketin ja tarkistussumman.
  • curl -fsSL .../install.sh | bash nousee näkyväksi asennustavaksi.
  • Asennuksen jälkeen käyttäjä pääsee suoraan bus-komentopintaan.
  • Lisätiedot löytyvät BusDK:n dokumentaatiosta.

BusDK:n kokeileminen tarkoittaa tähän asti lähdekoodin lataamista ja rakennusvaiheiden päättelemistä itse. Tämän muutoksen jälkeen käyttöönottopolku on ensimmäistä kertaa suora ja kopioitava: 

curl -fsSL \
  https://github.com/busdk/busdk/releases/latest/download/install.sh | bash

bus --help
bus: dispatch BusDK subcommands from PATH

Usage:
  bus [global flags] <command> [args...]

Behavior:
  Dispatches bus-<command> from PATH...

Julkaisuun tulee nyt mukaan asennusskripti, julkaistut paketit ja tarkistussummat, joiden ympärille myös README ja nopea asennusohje rakennetaan uudelleen. BusDK:n pystyy tämän jälkeen asentamaan suoraan julkaistusta versiosta ja tarkistamaan heti bus --help-komennolla. Nykyinen asennus- ja käyttöpolku löytyy BusDK:n dokumentaatiosta.
