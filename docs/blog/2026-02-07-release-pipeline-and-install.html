BusDK Update

Release workflow ja install-polku nousivat näkyviin

BusDK:n release-puolella tapahtui paljon kerralla: julkaisuputki, publish-helper, tagien käsittely ja docs-linkitys etenivät samaan suuntaan.

`busdk.com`-sivusto sai quick install -osion ja näkyvämmän moduulipinnan. Tämä oli yksi ensimmäisistä hetkistä, jolloin BusDK:ta pystyi sekä julkaisemaan että kokeilemaan ilman sisäpiiritietoa.

7.2.2026Release workflowQuick install

TL;DR

  • Merkitys: BusDK:n kokeilu ja jakelu tulivat paljon helpommiksi samana päivänä.
  • Toteutus: GitHub-release-putki ja publish-helper alkoivat hoitaa tageja, artefakteja ja docs-linkitystä järjestelmällisesti.
  • Saatavuus: tälle päivälle osuvat myös tagit v0.0.1 ... v0.0.10.

Mitä juuri tänään muuttui

Root-repoon tuli release workflow, joka alkoi paketoida julkaisuja. Install-skripti lisättiin release-artifakteihin, julkaisutekstejä kirjoitettiin uusiksi ja publish-helper opetti putkea pushaamaan tageja myös moduleille. Samalla README ja install-snippetit siirrettiin korostamaan quick install -polkua.

`busdk.com`-repolla tämä näkyi heti: samalle päivälle osuvat quick install -osion lisäys, moduulilistauksen täydentäminen ja tyylien erottaminen omaan CSS-tiedostoon. Julkinen sivu alkoi vastata samaa viestiä kuin release-putki.
