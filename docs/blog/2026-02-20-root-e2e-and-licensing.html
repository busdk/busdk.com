BusDK Update

Koko BusDK:n testiajo, lisenssiviesti ja Windows-polku tarkentuvat

20.2.2026 tekee BusDK:n arvioinnista aiempaa suoraviivaisempaa kolmella eri tavalla: koko työkaluketjulle tulee yhteinen e2e-ajo, lisenssiviesti täsmentyy ja myös Windows-käyttöpolku tulee näkyviin.

20.2.2026 Testaus Lisenssi Windows

Tiiviisti

TL;DR

  • Koko BusDK:lle tulee yksi yhteinen e2e-ajokomento.
  • Lisenssiviesti muuttuu näkyvämmäksi ja täsmällisemmäksi.
  • Windows-asennus ei enää jää sivuhuomioksi.

Yhteinen testiajo näkyi heti BusDK:n yhteisessä työpinnan käytössä. make listasi nyt sekä koko työkaluketjun testit että e2e-ajon samaan paikkaan: 

make
Targets:
  test        Run module test suites
  e2e         Run module end-to-end suites (when target exists)

Tämä on tärkeä muutos erityisesti silloin, kun BusDK:ta ei arvioida vain yksittäisen moduulin vaan kokonaisuuden kautta. Samalla lisenssidokumentaatio ja julkaisuohjeet alkavat kertoa selvemmin, millä ehdoilla binäärit ovat käytettävissä ja miten sama polku toimii myös Windowsissa. Olennainen lopputulos on yksinkertainen: BusDK:n saa helpommin kokeiltavaksi ja sen rajoista saa aiempaa vähemmän epäselvän kuvan.
