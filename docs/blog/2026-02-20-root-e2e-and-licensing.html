BusDK Update

Koko BusDK:n testiajo, lisenssiviesti ja Windows-polku tarkentuivat

20.2.2026 teki BusDK:n arvioinnista aiempaa suoraviivaisempaa kolmella eri tavalla: koko työkaluketjulle tuli yhteinen e2e-ajo, lisenssiviesti täsmentyi ja myös Windows-käyttöpolku tuli näkyviin.

20.2.2026 Testaus Lisenssi Windows

Tiiviisti

TL;DR

  • Koko BusDK:lle tuli yksi yhteinen e2e-ajokomento.
  • Lisenssiviesti muuttui näkyvämmäksi ja täsmällisemmäksi.
  • Windows-asennus ei enää jäänyt sivuhuomioksi.

Yhteinen testiajo näkyi heti BusDK:n yhteisessä työpinnan käytössä. make listasi nyt sekä koko työkaluketjun testit että e2e-ajon samaan paikkaan: 

make
Targets:
  test        Run module test suites
  e2e         Run module end-to-end suites (when target exists)

Tämä on tärkeä muutos erityisesti silloin, kun BusDK:ta ei arvioida vain yksittäisen moduulin vaan kokonaisuuden kautta. Samalla lisenssidokumentaatio ja julkaisuohjeet alkoivat kertoa selvemmin, millä ehdoilla binäärit ovat käytettävissä ja miten sama polku toimii myös Windowsissa. Lukijan kannalta olennainen lopputulos oli yksinkertainen: BusDK:n sai helpommin kokeiltavaksi ja sen rajoista sai aiempaa vähemmän epäselvän kuvan.
