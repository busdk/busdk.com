Bus AI Platform

Self-hostable AI infrastructure for product builders.

Bus AI Platform helps technical teams run AI services on infrastructure they control: OpenAI-compatible APIs, inference runtime control, local-to-remote deployment, auth, usage metering, billing, VM and container runtime support, and service lifecycle hooks.

Read docs Discuss deployment

What it is for

This product is for technical founders, SaaS developers, and platform teams that need AI APIs, runtime control, product controls, and deployment paths without building a custom pile of gateways, scripts, usage hooks, and billing glue.

Core workflows

  • Run a local AI service and move toward deployed environments.
  • Use OpenAI-compatible interfaces while retaining backend choice.
  • Add login, entitlements, usage capture, billing, and service tokens.
  • Operate VM, container, terminal, cloud, database, node, and inference surfaces.

Modules behind the product

The product owns model/inference providers, runtime modules, deployment and infrastructure operators, auth/session providers, usage metering, billing, Stripe, cloud/database/node integrations, and SSH runner support.
