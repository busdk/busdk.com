Bus Books

Auditable financial workflows for humans and agentic AI.

Bus Books connects bookkeeping UI, invoices, evidence, reconciliation, validation, reports, deterministic formulas, PDFs, CLI, API, and agent-facing financial tools over the same inspectable workspace data.

Read docs Book a pilot

What it is for

This product is for founders, bookkeepers, accountants, finance operators, auditors, and technical evaluators who need financial work to remain reproducible, inspectable, and connected to source evidence.

Core workflows

  • Bring invoices, receipts, bank data, and attachments into one workspace.
  • Move from inbox items to journal entries, reconciled bank transactions, and reports.
  • Validate periods, VAT, reports, formulas, and evidence packs before relying on them.
  • Use UI, CLI, API, and agent tools against the same financial data.

Modules behind the product

Bus Books includes the accounting engine, books UI, ledger/daybook, accounting portal, data workbench, sheets, files, attachments, replay, Bus Formula Language, PDF rendering, validation, VAT, reports, bank, invoices, and related accounting domain modules.
