Bus Books

Modules behind the bookkeeping product.

Bus Books is the one public accounting UI product. The accounting engine and related modules are proof of determinism and auditability, not separate buyer-facing products.

Core product modules

  • Books UI, accounting portal, ledger/daybook, inbox, attachments, and data workbench.
  • Accounts, journal, periods, invoices, bank, reconciliation, VAT, reports, and validation.
  • Bus Formula Language, sheets, files, replay, PDF rendering, and API provider surfaces.
  • Agent-facing finance tools that operate over the same workspace data.

Evaluator path

Start with the Bus Books docs for workflows and data boundaries, then use the module reference to inspect command and dataset behavior.
