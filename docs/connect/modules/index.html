Bus Connect Modules

What a deployment includes.

Bus Connect is deliberately small: one program to install and one other Bus product to run alongside it. There is nothing else to license, subscribe to, or wire together.

Modules behind the product

Bus Connect is a single bus-connect program that serves your public address, prices and accepts payments, and keeps each conversation separate. It stores conversations through bus-events, reached over the Events API provider, under an identity issued by the identities provider. Shared help conventions come from bus-help.

Bus Events is where durability comes from: your conversations survive a restart of either service and stay unreadable to anything else on the same platform. Bus Connect brings no database of its own for you to choose, run, or back up, and a simpler local storage option covers evaluation without any other service running.

It adds no directory of recipients, tenancy, webhooks, or platform integrations. See the module documentation for configuration, storage options, and operational detail.
